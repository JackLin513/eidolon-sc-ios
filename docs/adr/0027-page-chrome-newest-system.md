# ADR-0027：页面骨架按最新系统设计，通话条升到导航之上

日期：2026-11-02
状态：已接受

## 背景

#64 把根导航改成「对话 / 玩法 / 设置」三个 tab 后，收起的通话条仍放在每个列表的 `safeAreaInset(edge: .top)` 里。iOS 26 的浮动 tab 栏和导航栏会把紧贴滚动内容顶部的颜色吸到导航栏上：通话条的深色背景把整条导航栏（包括大标题）染成 `#111111`，标题被盖住，看起来就是页面顶部一大块黑边。真机上三个一级 tab 都能复现。

这不是通话条本身的颜色问题，而是它被放进了导航栏的滚动边缘。把通话条移到 `NavigationStack` 外面之后，导航栏不再采样它的颜色，标题回来；通话条仍然横跨页面顶部，状态栏区域跟着变成深色，读起来像一条真正的「通话中」横幅。

同时，页面骨架正在重构，下一步要适配 iPad 和 iPhone Duo。仓库的部署目标已经是 iOS 26，应该直接用当前系统的导航与 tab API，而不是先写旧形态以后再改。

## 决定

1. **一级 tab 用 `Tab` 值 API。** `TabView(selection:)` 里每个页面写成 `Tab("对话", systemImage:..., value:) { ... }`，不再用 `.tabItem` + `.tag`。同一套 tab 在 iPad 上可以变成侧边栏，在 iPhone 上使用新的浮动 tab 栏；以后适配 iPhone Duo 时不用重写 tab 定义。
2. **收起的通话条放在每个 tab 的导航之上。** 对话列表、玩法、设置都用 `VStack { CallBar(); NavigationStack { ... } }`，通话条属于 tab 的外壳而不是列表内容。这样：
   - 通话条在 tab 内推入的页面（礼物、成就、设置子页）上继续存在；
   - 导航栏不再采样通话条的深色背景，大标题始终可见；
   - iOS 26 把通话条的颜色延伸进状态栏，形成一条完整的深色横幅，这是有意接受的视觉效果。
3. **对话 tab 的外壳始终画一条通话条。** 它位于 `NavigationStack` 之上，角色列表和她的当前对话共用这一条；对话页不再自己画，避免两条。这样推进/返回对话时导航排版不随路径变化，角色列表不会上下跳。历史、酒吧、换衣装这些整屏页或弹层继续用自己的通话条。对话页整屏隐藏一级 tab 栏，通话收起时也一样。
4. **只有展开的通话层强制深色。** 收起时 `CallView` 不再用 `.preferredColorScheme(.dark)` 把下面三个 tab 一起拉进深色模式；深色只属于展开的通话层和通话条本身。
5. **调试启动只开一次对话。** `EIDOLON_OPEN_CHARACTER` 用一次性消费，返回列表后不会再被根页面的 `.task` 重新推入；这也是「收起通话后返回」能工作的前提。

## 后果

- 通话条从「页面内容」变成「tab 外壳」：新增一级 tab 时要在外壳里放一条，而不是在每个列表里加 `safeAreaInset`。
- 页面顶部的顺序固定为：状态栏 → 通话条（有通话且收起时）→ 导航栏 → 内容。iPad 和 iPhone Duo 适配时优先调整横幅宽度/是否悬浮，而不是把通话条塞回导航栏。
- iOS 26 的导航栏边缘采样是这次 bug 的根因；以后若再在导航栏边缘放带底色的内容，先在真机上检查标题是否还在。
- UI 测试 `testCollapsedCallBannerStaysAboveEachTabsTitle` 锁住「通话条在三个 tab 的标题之上」；`testChatHidesTheTabBar` 继续锁住对话页整屏。

## 修订记录

- 2026-11-02：接受。修订 ADR-0023 第 4 条中「通话条在导航栏下方」的摆放规则：一级 tab 页面改为在导航之上。
- 2026-11-04（#94）：根导航增加「朋友圈」占位 tab，一级 tab 变为「对话 / 朋友圈 / 玩法 / 设置」四个；玩法页改为礼物、成就、日历、她的周期、酒吧五张卡。通话条在导航之上的摆放规则不变，四个 tab 都适用。
- 2026-11-04（bug）：收起的通话不再把一级 tab 栏带回对话页。tab 栏与输入栏抢底边，进入/返回对话时会上下抽动；对话页现在始终整屏，回到通话用页面里的通话条，去别的 tab 先退回角色列表。
- 2026-11-04（bug）：通话条从「路径为空才插进角色列表」改为对话 tab 外壳常驻。原来返回列表时路径变空，通话条插入把导航和大标题往下推 52pt，看起来就是跳动；现在列表和当前对话共用外壳里的同一条，路径变化不再改排版。
