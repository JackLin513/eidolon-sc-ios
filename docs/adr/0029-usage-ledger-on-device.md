# ADR-0029：服务调用记录、估算费用与统计都在端上

日期：2026-11-04
状态：已接受

## 背景

上游的「统计」页只算用户和角色们的往来，不含 token 和花费；用量与花费在管理者的看板里，来自服务端的运行记录和按 15 分钟汇总的表。本仓库是手机独立运行（ADR-0001），没有后台，也没有部署者的 key 与用户自带 key 之分：所有模型都是制作人自己的 key。制作人需要两件不同的事——和角色们往来多少，以及每个 API 用了多少、按现价大概花了多少。

服务端还有在线价格目录、按管理员设置覆盖单价、按币种分配额度和账单；这些在端上没有对应物，也不该让页面依赖网络才能算钱。

## 决定

1. **本地新增一张服务调用表。** 用户库 schema 升到 v19，新增 `service_calls`：时间、服务、提供方主机、模型、操作、单位、输入/输出/缓存输入、是否估算、延迟、错误、关联对话。它不引用对话外键：删掉历史对话，花过的钱仍然留着。旧版本没有记录，不从历史消息补算，页面写明「从这次更新开始统计」。
2. **每个外部调用写一条。** 对话模型（文本、通话、标题、记忆、搭话、酒吧）、判断、情绪判断、embedding、rerank、Fish Audio TTS、Soniox/百炼 STT；生图的单位先留好 `images`，下一分支接入。TTS 记文本的 UTF-8 字节，drama-3 按字符（与 Fish Audio 的计费一致）；STT 记接通后的秒数；embedding/rerank 记服务商报告的输入 token，没报就按文本估算。
3. **真实用量优先，估算有标记。** OpenAI 兼容流打开 `stream_options.include_usage`，Anthropic 读 `message_start`/`message_delta`，Responses 读 `response.completed`；拿不到时用本地估算：CJK 字符按 1 token，其他非空白文本按 UTF-8 字节/4，向上取整，空格不计。估算条目 `estimated = 1`，页面显示「估算」。
4. **价格是内置表加制作人覆盖。** 键是「提供方主机 + 模型 + 单位」，照上游 2026-10-07 的 PRESETS 搬；DeepSeek、Gemini 对话模型按官方页补，并写抓取日期。`price_overrides` 按同一键覆盖输入/输出/缓存输入单价和币种，可恢复内置价。费用在读取时按现价重算，所以改价会影响历史估算，这是有意的：价格表错了就该重算。
   百炼实时识别 3.1 官方按 token 计费（北京 6/4.5 元每百万输入/输出），而端上仍按音频秒数记录；价格表按官方音频换算 25 token/秒折成 **0.54 元/小时输入**，标「估算」，输出文本暂不估。3.0 是官方按秒计费，直接用 **1.188 元/小时**（0.00033 元/秒），不算估算。上游两者都不标价，这里为了制作人能看到大概开销而按此折算；页面上仍显示秒数。
5. **合计按币种分开，不换算汇率。** 人民币和美元各显示各的，不扣免费额度；没有单价的模型只显示用量和「未设单价」，本地/私有主机（localhost、192.168、Tailscale 的 100.64/10 等）按 0 元。页面写明「估算，不是账单」和价格表日期。
6. **两个只读接口。** `statsSummary(range:now:timeZone:)` 和 `usageStats(range:now:timeZone:)` 都在 `Eidolon` 上，只读不写；日期和钟点用制作人档案的时区。统计沿用上游口径：往来是用户消息或礼物事件，只算还在的对话；成就数照成就自己记下的算；通话只算接通了的；区间是近 30 天、近 365 天或全部，今天算最后一天。用量区间相同，但记录不受删对话影响。
7. **页面用 Swift Charts 与自绘网格。** 设置里两个入口，各自一页：统计是画像、数字、52 周热力图、好感度、成就、区间数字、角色排行、24 小时分布和礼物；用量与花费是区间、币种合计、按服务/模型展开、每日趋势、单价入口和清空。热力图用五级深浅的自绘网格，与上游一致；数字用等宽字体，图表有 VoiceOver 摘要。

## 后果

- 端上没有任何历史用量，第一次打开用量页是空的；这是接受的取舍，不伪造历史。
- 估算不是账单；服务商没报用量时数字偏差取决于文本长度规则，页面明确标注。
- 价格表会过时，所以覆盖功能是必须的；在线目录和自动抓取不在范围内。
- 服务调用记录永久保留，制作人可以手动清空；清空不影响价格设置。
- 生图在下一分支接入时只需要写 `unit = images` 的调用，价格表已有 NovelAI 和 GPT Image 2 的预设。
- 统计和用量都不进数据包，也不参与上游的 oracle；提示词不变。
