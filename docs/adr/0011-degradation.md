# 分层降级

断网或服务失败时不整体失效：本地历史与内容始终可读；判断失败按上游语义降级（仍按 `references` 检索、好感不变）照常回复；向量化失败则本回合不检索；重排失败时参考资料取向量最近的几条，记忆则不带；对话模型失败则保留用户输入、显示重试，不写入半截回复。

通话同样分层：识别连接断了显示重连、通话不挂；某一段合成失败跳过该段（台词卡跟着声音走，不翻到没念出来的那段）；配音服务整体不可用（密钥被拒、欠费、空音频，或者这次通话还从没合成出任何一段时的模型/音色不支持、请求被拒）不算「某一段」，按上游以 `not_connected` / `dropped` 结束通话，没有填密钥时只有台词卡；麦克风打不开另记 `mic_denied`；回合失败提示「她那边没声音」，通话继续，不写半截回复。

**后果**：每条链路都要显式区分「失败的后果」，不能默认抛错。
