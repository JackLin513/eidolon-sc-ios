# ADR-0030：照片在端上生成，提示词分叉随内容包

日期：2026-11-05
状态：已接受

## 背景

照片是上游最自然的一块：制作人明确要一张照片时，她按当时的穿着、地点和动作写一个标签，服务端用 NovelAI 生成。本仓库此前把照片列为不做（ADR-0001），她只能用自己的话推掉。

端上没有后台，也没有部署者的密钥：生图必须由 iPhone 直接调用制作人自己的服务。上游把照片标签、黑名单、外貌 tag 和提示词都放在服务端；这些在端上要从内容包里读。上游只做全年龄照片，而制作者已经决定：成人模式对内容包标注 18 岁及以上的角色开放 R，普通模式仍然全年龄。

## 决定

1. **生图是一个适配器接口，不是一次性的请求。** `ImageGenerating` 只有一个 `generate(request, settings)`；两个实现分支：NovelAI 原生格式（`/ai/generate-image`，V4 请求体，返回 ZIP）和 OpenAI 图像格式（`/images/generations`，`b64_json` 或 `url`）。格式由制作人选，不自动探测。另有可选的 GPT Image，只给朋友圈里没有人的配图用，不参与她的照片。
2. **密钥只进钥匙串。** NovelAI / OpenAI 图像各一份；地址、模型、画风、每小时上限存偏好设置。`.env` 导入按上游的 `NOVELAI_*`、`GPT_IMAGE_*` 与 `EIDOLON_PHOTOS_PER_HOUR` 读入，空值不覆盖。
3. **提示词在端上分叉，但来源是内容包。** 判断模型在生图、照片 tag 表和角色 tag 都在时多答一道 `wants_photo`；她在回复最前面写 `<photo>` 标签，标签闭合就开始生成。标签的清洗、改写、黑名单剥除、默认补全和提示词拼装都在端上，表与角色外貌 tag 随内容包格式 5 一起导入（`characters/photo_tags.json`、角色条目的 `photo_tag` / `photo_appearance`）。没有判断模型、没有生图或没有角色 tag 时，她的提示词保持原文「你发不了照片」。
4. **照片是回合的一部分。** `<photo>` 只在回复最前面生效，不进入台词、字幕、语音、判断和记忆输入；原始标签留在她的历史里，失败的标签带 `status="failed"`，让她知道没送到。图片转成无元数据的 JPEG，存在用户目录的 `images/photos/`，数据库只记挂接、状态和原因。
5. **一个队列、一个总时限、不自动重试。** 同时只跑一张；用户照片优先于朋友圈配图；照片总时限 90 秒（含排队），超时按失败处理并让出队列位置。真实调用写一条 `unit = images` 的用量记录：出图记 1 张，报错或超时记 0 张，不记标签原文。
6. **额度按滚动一小时，失败退还。** 默认每小时 5 张，可设 0 表示不限；pending 与 ready 都占名额，failed 不占。额度用完时判断照常问她是不是在要照片，她按提示用自己的话推掉，对话里出现「HH:MM 以后可以再要」的胶囊；HH:MM 是最老那张照片满一小时的时间。
7. **生命周期跟着对话走。** 启动时把遗留的 pending 改成超时，并清理没有行指向的图片文件；删除历史对话时照片行随消息级联、文件一起删除；照片不能单独删。
8. **成人 R 只对成年角色开放。** 成人模式开启且角色明确 18 岁及以上时，标签可写 `rating`（缺省或非法回落到 questionable），用 Full 模型和成人负面；普通模式、未满 18 岁和年龄不明的角色永远用 Curated 模型、全年龄负面和 `rating:general`。成人模式仍剥掉外貌、画风和 `people` 类 tag；年龄由资格和角色年龄把关，不靠模型自觉。失败时照普通失败显示，不换 key、不换模型。

## 后果

- 生图费用现在是制作人自己的直接开销，按张计；照片默认每小时 5 张，避免一次测试刷光额度。
- 成人 R 依赖服务商的实际行为；成人模式只表示允许，不保证每张成功。残余风险由制作人承担，普通模式不受影响。
- 内容包格式 5 起必须带 `places.json` 和 `photo_tags.json`；旧包要在 Mac 上重新导出。
- 提示词多了一段照片说明，oracle 的全年龄场景在无生图配置时仍走「你发不了照片」，七个场景保持逐字一致。
- ADR-0001 范围里的「照片不做」由本 ADR 取代；照片仍是端上生成，没有新增后台。
