# 判断模型只在经前、经期多问一道体贴题，原有判断题仍不看她的状态

好感度的判断原来对所有角色一个标准，不看她的回复、档位和状态。周期要让经前、经期「高风险高回报」（见词汇表「周期」「体贴」），我们没有动原来那几道题，而是只在这几天往同一个请求里加一道三档的体贴题，她处在哪个阶段只写在这道题的题面里；倍数（负档 ×2）、额外加减和降低的挂断阈值都在判断之后按阶段套用。这样原有的评测基线和阈值照旧有效，其他日子请求和现在完全一样，开关一关就回到原样。

## Considered Options

- **把她的状态告诉判断模型，让原有五档自己往两头偏**：少一道题，但现有评测集和阈值都要重做，也说不清偏了多少、算不算公平。
- **只给原有扣分乘倍数、不加题**：最省，但抓不到「她说累，用户却催她去训练」这类按原标准判成没有影响的话，「体贴」也无从加分。

## Consequences

- `affinity_judge.py` 开头「一个标准」的说明要改成：原有题仍是，体贴题是唯一知道她阶段的例外。
- 体贴题要有自己的评测集（`[[considerate]]`），并检查它加进请求后其他题的结论不变。
- 运行记录不记体贴题的答案，否则管理者能看出她的阶段。
