# 通话在端上自己实现

不跑 WebRTC 也不跑 Pipecat：麦克风经 `AVAudioEngine` 送 Soniox 实时识别，回合由 `EidolonCore` 的对话引擎产生，日语按段流式送 Fish Audio 播放。起止完全信 Soniox 的 endpoint 事件（不另加本地 VAD），最后一句话之后再等 4 秒算补充宽限；只有「她已经出声且至少一段说完」之后开口才算打断。补充丢弃整条回复、同回合重答、不写库；打断则把已生成的段（含可能没播完的尾段）补全后入库。静默接通，没有开场白；上限 60 分钟，不限回合。

**后果**：回声消除、打断延迟、Fish 重连都要自己调；上游的轮次策略改动需要手工同步。
