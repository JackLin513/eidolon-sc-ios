# 配置

App 本身没有账号：所有配置都在设置里，密钥存钥匙串（每家的密钥分开存，换服务不会读到别家的）。只有可选私有服务的登录在设置最上面的「账号」里。

## 服务

| 用途 | 用它做什么 | 密钥存哪 |
|---|---|---|
| 对话模型 | 说话、写记忆、生成标题、酒吧里的她 | 钥匙串 |
| 判断模型 | 好感打分、要不要查资料、情绪与点头、酒吧点单判读 | 钥匙串（每家一份） |
| 向量化 / 重排 | 剧情、资料、记忆的检索 | 钥匙串 |
| Soniox 或阿里云百炼 | 通话时的语音识别（设置里二选一） | 钥匙串（两家各一份） |
| Fish Audio | 通话时的语音合成 | 钥匙串 |
| NovelAI 或 OpenAI 图像 | 她发的照片（NovelAI 原生或 OpenAI 图像格式） | 钥匙串 |
| GPT Image（可选） | 朋友圈里没有人的配图，不参与照片 | 钥匙串 |

## 模型配置

设置 →「API 与模型」最上面是「模型配置」：每套配置保存协议、接口地址、模型名、自己的钥匙串密钥、max tokens 和额外参数；点一下即切换并立即保存生效，不需要再按「保存」。历史回合、文字氛围模式、成人模式和思考强度是全局的。

第一次打开时，现有对话模型会原样变成「当前配置」；列表里另有「DeepSeek」和「家里本地」两条模板（本地地址预填 `http://192.0.2.10:8080/v1`，模型名按 Windows 上 llama.cpp 实际暴露的名字填），都可以改、复制和删除。切换只换对话模型；后台模型留空时自动跟着它走，判断、检索、通话和生图不变。最后一个配置不能删；删除当前配置会先切到另一套。

每个输入框下面有一行说明，写「填什么」和「留空会怎样」；分区的整体说明仍在分区底部。

## 判断模型

设置 →「判断模型」里四选一（ADR-0016）。每家各存一份密钥，换服务不会读到别家的密钥。

- **阿里云百炼**（默认）：业务空间 ID、地域（北京 / 新加坡）、百炼密钥；模型默认 `decision-model-preview`。地址由业务空间 ID 和地域拼出，按 decision-model 的阈值读概率。
- **Jev**：接口地址（默认 `https://openrouter.ai/api/v1`，用它加 `/systemone`）、模型名（默认 `typesafe/jev-1.13`）、密钥。OpenRouter、Vercel AI Gateway 或 TypeSafe 自己的地址都可以，只要提供 `/systemone`。
- **Cloudflare**：账号 ID、模型名（`clef` 或 `clef-flash`）、Workers AI 的 API token。地址按账号 ID 与模型名拼出，请求体里只写裸模型名；`clef` 和 `clef-flash` 各用自己那一行阈值，每天免费 1 万 neurons。
- **对话模型（JSON）**：用对话模型自己再判一次，读它的 JSON 回答；地址、模型名和密钥留空时沿用对话模型的设置。

模型名不属于 jev / clef / clef-flash / decision-model 任何一族（没有校准）时，按 jev 的阈值算，设置页与回合追踪里会写明「这个模型没有校准，按 Jev 的阈值算」。

「测试判断模型」用屏幕上当前的配置发一次只含一道是非题的请求：成功显示服务、模型与阈值族；失败分开说清业务空间 / 地域不匹配、密钥无效、模型名不对、账号不对、当天额度用完，其余原样显示服务返回的错误。测试不保存配置，改完记得点「保存」。

情绪判断只在 System One 类判断器（百炼 / Jev / Cloudflare）上启用，聊天模型判断器不判断情绪。设置里最低概率留空用家族阈值（jev 0.5，其余 0.4），超时默认 1.5 秒。

## 生图

设置 →「API 与模型」→「生图」。接口形式二选一：NovelAI 原生格式（地址写到域名根）或 OpenAI 图像格式（地址写到 `/v1`）；地址、普通模型（默认 `nai-diffusion-5-curated`）、成人模型（默认 `nai-diffusion-5-full`）、画风和每小时上限（默认 5 张，0 不限）都在这里。密钥只存钥匙串。

「试一张」用固定的全年龄提示词和当前画风真的生成一张图，会花一张的钱；NovelAI 原生格式固定用更便宜的 4.5 Curated 模型（OpenAI 图像格式用你填的模型）。这张图不进用量记录，也不占每小时的照片额度；点之前会确认。

GPT Image 单独一组，默认关闭，只给朋友圈里没有人的风景、食物和物品配图用；地址、模型、质量和密钥各自一份。

成人模式只对内容包标注 18 岁及以上的角色开放：用成人模型和成人负面，标签可以写 `rating`；普通模式、未满 18 岁和年龄不明的角色始终是全年龄。

## 朋友圈

设置 →「朋友圈」：开关（默认关）、每天动态上限（默认 3，最少 1）、每天回复上限（默认 10，0 表示不回复）、地图服务（Apple 地图默认，可切 Google / OpenStreetMap / 高德）、新动态通知。调试模式打开后另有「朋友圈也允许 R 配图」，只在成人模式也开着、且画面里所有角色都明确 18 岁以上时生效；普通朋友圈始终全年龄。

- 排计划按东京时间；动态里的地点来自内容包的地点池，天气取 Open-Meteo 的东京实时值（不联网或取不到时不显示，不编）；地图链接不申请 key，天气也不走网络代理设置。
- 打开 App、回到前台、在前台每分钟、打开朋友圈页时都会补齐今天到点的内容；`BGProcessingTask`（要求网络、不要求充电，最早 15 分钟后）做机会式后台生成，系统可能不执行。后台成功生成新动态或她的回复才发本地通知，文案不带正文；前台补齐不发通知。
- 关闭朋友圈不删除数据，只是不再排计划、不再生成；已有动态照常过期。朋友圈不进内容包，也不进数据包；删除对话不影响朋友圈。
- 从 `.env` 导入时会带上 `NOVELAI_*`、`GPT_IMAGE_*`、`EIDOLON_PHOTOS_PER_HOUR`；朋友圈的开关与上限在 App 里设置。
