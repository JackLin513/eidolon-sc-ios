## 1. 这一版欢迎页是什么

页面不是重写的，是**上游 `app/(landing)` 的源码原样搬进仓库**，用 Vite 构建成静态产物塞进 App：

| 位置 | 内容 |
|---|---|
| `welcome/` | 最小的 Vite + React 工程；`src/landing/` 由 `tools/sync_welcome_page.sh` 从上游拷入，不要手改 |
| `EidolonIOS/Resources/Welcome/` | 名册 `welcome.json`、30 段招呼、4 个体素小人、29 套默认衣装（约 28 MB） |
| `EidolonIOS/Resources/WelcomePage/` | 构建产物（`tools/build_welcome_page.sh` 生成，**要提交**） |
| `EidolonIOS/Features/Welcome/` | 原生宿主：`WKWebView`、自定义 scheme、兜底画面、跳过 |

页面通过 `eidolon-welcome://app/…`（页面）和 `eidolon-welcome://media/…`（素材）取东西，不联网、不导航、不开窗。

## 2. 照搬源码踩过的坑（都已经修好，别再踩）

1. **档位脚本必须外链**。CSP 的 `script-src 'self'` 会拦内联脚本；被拦掉以后 `<html>` 上没有 `data-lp-layout`，整页退回静止版式，滚动的动画全没了。构建时由 `vite.config.ts` 写出 `tier.js`。
2. **必须补 Tailwind 的 preflight**。上游 `globals.css` 第一行就是它，去掉以后 body 带 8px 默认边距，所有按视口算的位置整体右移（真机上偏 8pt）。
3. **声音不能直接给 `<audio>`**。自定义 scheme 下播放要交给系统媒体进程，`blob:` 和 scheme 地址都读不到（`NotSupportedError`）。读成 **`data:` 地址**再播。
4. **接通音、挂断音是独立文件**（`public/sounds/connect.ogg`、`hang-up.mp3`），只搬 `public/landing` 会静默 404；scheme handler 要认 `audio/ogg`。
5. **WKWebView 要放开手势播放策略**：`mediaTypesRequiringUserActionForPlayback = []`，否则接听后的开场白（不在手势里）会被拒成 `NotAllowedError`。
6. **WKWebView 必须透明**（`isOpaque = false`），否则 iframe 里的立绘会被合成成白底。
7. **立绘不能用上游那个 React 组件**（`Stand.tsx` + `StandEngine`）：在这个文档里画 10 帧左右，WebKit 直接杀掉网页进程（`webContentProcessDidTerminate`）。**换成 iframe 跑 App 自己那份 `stand.html` + `stand-player.js` 就完全正常**。已排除：画布尺寸、DPR、透明、WebView 配置、素材版本、请求风暴、页面 JS 体积。
8. **播放器要的是轨道级 pose**，不是落地页的 `{mood, speaking}`：`{body, face, mouth:{name, open}, eye}`。页面里照 `StandAnimator.pose` 翻了一份映射。
9. **相机要等布局完成再算**（`loaded` 那一刻 `innerWidth` 可能还是 0），并且比上游 `knees` 取景退了 12%，用户觉得这个比例接近上游。
10. 立绘那一格是 `pointer-events: none`，滑动手势要穿过去到光谱上。

## 3. 这一版的已知差异

- 立绘是 iframe（上游是同一文档里的 React 组件），动画、登场、取景是复刻的，不是逐帧一致。
- 第 4 幕手机里的卡图仍是静态图（和上游一致），不显示立绘。
- 没有换衣装（只带每位的默认衣装），没有登录入口（右上角只有原生「跳过」）。
- 第 6、7 幕文案按端上的实情改写过（没有部署服务、没有账号系统）。
