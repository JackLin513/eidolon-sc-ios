# 06: 点单的全部说法、备忘和名字检查

**What to build:** 她点单不再只直说名字，九种说法按占比出现，服务器从目标饮品推出算对的范围和「上得最好」的几款。备忘由服务器套模板写；她点单时说漏或该说没说名字，服务器能发现，先重写一次，再不过就换模板句。见规格「点单怎么抽」「点单备忘」「判定」「名字检查」，以及票 05、07 的答案。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 说法和占比照规格的表：直说饮品名 40%、饮品名加大杯 7%、说口味 12%、说种类 12%、几个条件叠加 8%、照描述打比方 8%、「来杯我喜欢的」4%、「你拿主意」4%、「老样子」5%。这一单出不了的说法去掉，其余按比例摊开。各项比例和门槛都是常量。
- [ ] 能出的条件：
  - 新手（这位用户玩完的光顾不到 3 次）不出打比方和几个条件叠加；
  - 她和这位用户没玩完过光顾时，不出「老样子」和「来杯我喜欢的」；
  - 「来杯我喜欢的」要求目标从爱喝的桶里抽出；
  - 名字加大杯要求目标有大杯；
  - 打比方要求目标有描述；
  - 几个条件叠加要求目标至少有一个附加条件能出。
- [ ] 每种说法算对的范围和「上得最好」照表；几个条件叠加的组法照规格：口味或种类取一样，加冰、无酒精、大杯再取一到两样。通用规则：她讨厌的口味在任何说法下都算上错；她没提到的条件不管；范围里没有她爱喝的，这一单就没有「上得最好」这一档。
- [ ] 酒量：目标是那 7 款能选 Karmotrine 的、说法又不是「老样子」时，酒量弱的 40%、中等的 10% 补一句「不要酒精」，强的不补。补了就照硬条件判，上了含酒的算上错。
- [ ] 「老样子」：上次那一单上对或上得最好时，认当时上的那款；上错时，认那一单的目标饮品。没有「上得最好」这一档。不受「第一单避开上次点过的」限制。
- [ ] 错在哪补齐，按这个顺序取第一条：讨厌的口味；说了不要酒精却有酒；「老样子」却不是上次那款；口味对了种类不对，或种类对了口味不对；完全不对。前两条在提示词里要求写成明显的不喜欢。
- [ ] 点单卡给模型的是说法、目标的英文名和日文名、口味、种类、描述（打比方时）、要提的条件、能不能说出名字；不给范围。
- [ ] 备忘每种说法的文字照规格（种类用菜单分类名）；打比方的复述她点单那句的中文字幕。
- [ ] 名字检查只看点单句。不该说名字的说法里，日语和中文字幕都不能出现目录里任何一款的英文名或日文名，比对时不分大小写、全角半角。该说名字的，中文字幕里要有英文名，或者日语里要有日文名。点单句先扣在服务器，检查过了才连同备忘推出去。不过：用同样的提示词加一句要求，只重写点单句，再调一次；还不过就换成这种说法的模板句，按需填进名字和条件。重写那次不算重试，不另计限额。
- [ ] 测试：每种说法的能出条件；每种说法下上得最好、上对、上错各一例，以及边界（没说大杯做了大杯、名字加大杯上小杯、说了无酒精上了含酒的、讨厌的口味碰上宽的说法、「老样子」认上次那几款、范围里没有爱喝的）；错在哪的每一种和先后顺序；酒量补「不要酒精」；每种说法的备忘文字；点单卡里不含范围；名字检查的英文名、日文名、大小写、全角半角各触发一次重写，重写还不过换模板句；点单句在检查前不推出去。
- [ ] 把 GLOSSARY「点单」和实现对一遍。pyright、ruff 通过；提交前跑 affected-tests。
