# 04: 起草：写死的句子

**What to build:** 仓库里新加 `characters/bar_lines.toml`，放所有不交给模型写的句子，启动时校验：
- **「请慢用」**：制作人每上一杯说的几句，中文。
- **点单的模板句**：名字检查两次都不过时顶上，按说法分。直说名字、名字加大杯这两种带 `{name_ja}`、`{name}` 占位，其余不带名字。每条日语加中文。
- **兜底的反应**：告别那次调用写不出来时用，按三档分（上得最好、上对、上错），每档几句，日语加中文。
- **兜底的告别**：同上，按醉没醉分两组。

句子写成通用的，不分角色，口气中性，哪位角色说都不突兀。做完先停下，等用户校对。见规格「写死的句子」和票 09 的答案。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 说法的名字和规格的说法表一一对应：直说饮品名、饮品名加大杯、说口味、说种类、几个条件叠加、照描述打比方、「来杯我喜欢的」、「你拿主意」、「老样子」。不带名字的模板句里不能出现任何饮品名。说口味、说种类、几个条件叠加这几种的模板句，要说得出这一单的条件：口味、种类、冰、大杯、不要酒精都用占位，由服务器填进去。
- [ ] 每组至少 3 句。日语是她的口吻，中文是字幕；「请慢用」只有中文。
- [ ] 校验：每一组都有，而且不空；占位只用规定的几个；每句都是单行。坏了报配置错误，并指出是哪一组。测试的 `CharacterConfig` 拷一份。
- [ ] 测试：真实文件通过校验；临时文件缺组、用了不认识的占位、不带名字的组里出现饮品名，各被拒。
- [ ] 做完停下，不往下做别的票。Comments 里列出全部句子，等用户校对，用户改完再关票。
