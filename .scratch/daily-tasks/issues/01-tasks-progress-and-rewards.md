# 01: 三项任务记进度、到账，礼物页显示

**What to build:** 每日任务从头走通。用户和任意角色有回合（打字的和通话里的都算）、送出礼物时，今天的三项任务（一个回合、送一件礼、十个回合）随之前进；做完一项自动加 1 次抽奖，同一项只加一次，不受 `MAX_DRAWS` 约束，北京时间 0 点换新、没做完的作废。礼物页抽奖台正下方出现「每日任务」一节，看得到三项做到哪了。这张票建好两样成就也要用的东西：回合和送礼两处只调用的「发生了什么」入口（规格里叫往来记账），以及幂等的「给用户发奖励」入口。见规格「三项任务」「记进度」「存什么」「发奖励」「`GET /api/gifts` 加两样」里的 `daily_tasks`、「礼物页那一节」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 往来记账：回合记下以后（打字回合和通话里的回合走的同一处）、送礼成功以后各调一次；开关关着时什么也不记；出错只记日志，不让回合或送礼失败
- [ ] 今日进度：每位用户一行（哪一天、回合数、送礼件数），按注入的时钟取北京时间的日期；不是今天就先清零再加，读的时候不是今天就当作 0
- [ ] 到账记录和幂等的发奖励入口：按（用户、键）唯一，同一个键只加一次抽奖；进度写入、到账记录、`gift_balances` 加次数在同一个事务、同一把锁里；加之前先照常补上每天发的那份；没有余额行的先建一行；可以超过 7
- [ ] 三项都写成常量：第 1 个回合、第 1 件礼物、累计第 10 个回合时各到账 1 次；之后再说话、再送礼不再加
- [ ] `GET /api/gifts` 加 `daily_tasks`：三项的 id、是否做完、进度和目标、给几次抽奖，加上下次换新的时刻；开关关着时为 null
- [ ] 两张新表登记进 `USER_DATA`，删除用户时一起删，不进数据包
- [ ] 礼物页抽奖台下面一节「每日任务」：标题、做完几项「1/3」、右边「0 点换新」（按制作人时区写）；三行，空圈或勾，第三项没做完时带「3/10」，右边「抽奖 ×1」；做完的字变淡、划掉。怎么显示收进 `lib/` 纯函数；开关关着时礼物页照旧是「礼物暂时没有开放」
- [ ] 后端测试（走 HTTP 接口，`FakeClock`）：三项各自做完的时机、只到账一次；几位角色的回合合起来算；通话里的回合算；冷却中送礼算；被拒、失败的回合不算；跨北京时间 0 点作废重来；已有 7 次时做完变成 8 次、第二天每天发的那份不把它压回去；开关关着不记、中途打开从那一刻起算、关了又打开已做完的还在；删历史对话后仍然做完；导入数据包不前进；删除用户后新表不剩行
- [ ] 前端测试：那一节的显示函数（打勾、「3/10」、「1/3」）
- [ ] 按 `docs/agents/local-acceptance.md` 在本地构建版上用 Playwright 看一眼礼物页那一节（宽屏、手机）
