# 06: 原型：周期子页长什么样

Type: prototype
Status: resolved
Blocked by: 05

## Question

玩法页的「周期」卡和子页长什么样（参考 LAPLACE 的资料卡、周期圆盘、月历和周期历史）：

- 29 位怎么排：先一份列表（每人一张小卡，显示用户自己推算出的下次经期）再点进某一位，还是先选人再看月历。
- 某一位的页面：月历上怎么画用户记的经期和推算的经前、经期、排卵日、易孕期；怎么记一次、改一次。
- 讲解和免责放哪；手机上怎么排。
- 玩法卡上的一句状态写什么。

原型放在 `prototype/cycles-page` 分支，按 `DESIGN.md` 和 shadcn 纪律。

## Comments

- 票 05 定了：月历上只画用户记的经期和推算的经期、经前（往后 3 个周期），**排卵日、易孕期不画在任何一位的月历上**，只在「怎么算的」里放一张 28 天例子的通用示意图。变淡有四种原因各一句（文案见票 05，可改字）；「过去的估算平均差 N 天」能比两个周期后才显示。一次记录是第一天 + 天数（默认估计值，1–10），不能记未来，可改可删。讲解六块、默认全收起、一次展开一块，每条句末一个小来源链接，「怎么算的」最后一条致谢 LAPLACE Cycles。一行说明「凭她的言行记下她的经期，这里替你推算。」、一行免责见票 05。推算由后端算好返回，原型里可以用假数据。

## Answer

2026-10-25 原型，用户看了 A、B、C 三个方案后选 B，按反馈改成 D 定稿。原型在 `origin/prototype/cycles-page`（`frontend/src/components/prototype-cycles/CyclesPrototype.tsx`，`/play/cycles?variant=D`，底部黄框切 A/B/C/D；`/play?card=A|B|C` 切卡的状态），假数据只在内存里，不进 main。

- **版式（D）**：一个子页，不分两级。从上到下：一行说明；对话列表同款的搜索框（「搜索名字或组合」，同一套 `matchesSearch`，搜不到「没有找到这位偶像」）加右边的筛选键；一排可横滑的头像条（48px 头像加短名，选中的铺中性 `bg-muted`），点头像换人、地址带 `?who=`；然后是她的那一块（注入她的 `herVars`）：电脑（≥ 768px）左右两栏，左边「下次经期推算在 10月31日（还有 6 天），经前从 10月26日 起。」、月历、图例和点中那一天的一条，右栏 15rem 放周期 / 经期 / 过去的估算平均差三行和变淡原因、「记过的经期」；手机上叠成一栏，顺序同上。两栏下面通栏放讲解，最后一行免责。
- **筛选**：电脑 Popover、手机 Drawer，标题「头像条里显示谁」，单选「全部 / 记过的 / 推算在经前、经期的 / 还没记过的」，每项后面 Meta 字号的「n 位」；不是「全部」时按钮右上角中性小点。搜索时不看筛选；选中的她一直留在条里。只在这次页面里记着，不存设备，也不和对话列表的「隐藏」相通（用户认可）。
- **记录不拉长页面**：右栏只露最近 3 次（只多 1 次时全露），下面 ghost `sm`「展开全部 n 次 / 收起」；电脑上右栏高度跟着左栏（月历那栏），展开后在栏里滚。每行：第一天、Subtitle 字号 muted 的「5 天 · 隔 29 天」、右端铅笔改。讲解不放侧栏：读一次的长内容放侧栏会一边短一边长，挪到两栏下面通栏，展开后行宽也合适。
- **月历**（用 A 的样子）：记下的经期整格铺她的 `--her-wall`、日期外一圈 2px `--her-mark`；推算的经期日期外一圈虚线 `--her-mark`；推算的经前整格铺中性 `bg-muted/60`，第一天格子底部一行 Meta 字号「经前」（只在电脑上）；变淡时推算的记号 `opacity-50`。下面一行图例。今天、选中的格子照日历子页（中性）。
- **记、改一次**：点月历的一天，下面那条写「10月20日 · 推算的经期」之类，右端「这天是第一天」（未来的日子不可用、写「不能记未来」）或落在记下的经期里时「改这次」；没点时一句「点一天来记下她这次经期的第一天。」。弹窗「记{角色名}的一次经期」：第一天是写着「2026年10月25日 周日」的 outline 按钮，点开小月历（周一在前、今天以后不能选），**不用原生日期框**（它的年月日顺序跟着浏览器语言走，英文浏览器是月/日/年）；天数是 −/+ 两个键夹着「5 天」（1–10）；改的时候左下多一个 destructive 字的「删除这次」。
- **讲解和免责**：六块默认收起、一次开一块（原型用 `<details name>`，规格换 shadcn Accordion），「怎么算的」里放 28 天的通用示意条；免责是最后一行 Meta 字号。
- **她的颜色**：用（用户确认）。上面月历的三处记号、弹窗里的 primary 都是她的颜色，规格要在 DESIGN.md「The Her-Colour-Only-Here Rule」和「The Scoped Colour Rule」里加上周期子页这一处。
- **玩法卡**：第四张「周期」卡跟在「日历」后面，最后一行只剩一张可以接受。图标原型用 Lucide `CalendarHeart`。状态没让用户单独挑，规格按 A 的写法起草：「记过 n 位 · 最近 {短名} M月D日」，没记过任何人时是那行说明。
- 没用上的：A（名单进人，两级）、C（圆盘和周期条、讲解单独标签）。
