# 周期

Label: wayfinder:map

## Destination

一到两份可以直接 `/to-spec` 再拆票实现的规格，所需的决定全部定下：每位用户的每位角色各有一个周期，她在经前和经期的言行、好感度和挂断跟着变；玩法页新加一张「周期」卡，用户凭她的蛛丝马迹记录经期，页面替用户推算并讲清怎么算的。

## Notes

- 用意是普及经期的保健知识，让人学会计算周期，也学会体贴。页面上的说明、原理、免责都按正常生理学写，引用医学文献；界面文案仍然要少（一行说明、可展开的原理、一行免责）。
- 术语以 `GLOSSARY.md` 的「周期」一节为准：周期、经期、经前、排卵日、易孕期。不说生理期、魔法期、PMS、危险期；说角色、制作人、回合，不说小偶像、聊天。
- 每张拍板类（grilling）票都要调用 grilling 和 domain-modeling 两个 skill。原型票调用 prototype，原型放在 `prototype/<name>` 分支。前端相关的先读 `frontend/AGENTS.md` 的「shadcn 纪律」，视觉以 `DESIGN.md` 为准。
- 这张地图只做计划，交付物是规格，不是实现。地图、票和规格放在计划分支 `feat/cycles`；调研结论放在 `research/<name>` 分支，只推送、不开 PR。
- 定图时已定（2026-10-24 的 grilling）：
  - 29 位角色都有周期（含はづき；18 位未满 18 岁，青春期来月经是正常常识）。**只有经前和经期影响她的言行、好感度和挂断**；排卵日、易孕期只出现在周期页的讲解里（票 05 定了不画在任何一位的月历上），不进她的对话、判断题，任何角色都不因此有暧昧或性方面的暗示。
  - 每个「用户 × 角色」各自随机一套参数（周期长度、经期天数、起点），同一部署里不同用户的同一位她各不相同；每个周期在基准上再小幅抖动，预测不会百发百中。
  - 线索：对话里一直隐晦流露（经期累、不舒服、不想出门；经前敏感、烦躁、易委屈），她不明说；经期内用户第一次来时给一条对话事件，说明是哪天开始的（比如「她好像从前天起就不太舒服」），整个经期没来就错过；经前不给提示。
  - 好感度「高风险高回报」：经前和经期不体贴的话扣得更重，体贴的话额外加分；**挂断也受影响**（用户 Q15 定的）。具体数在票 03。
  - 说话风格：每个阶段一段通用的状态描述放进每回合的上下文，由角色本身的性格演绎；不给 29 人分别写。卵泡期、排卵期不注入任何东西。
  - 文字对话、通话、主动消息都跟着周期；她发的照片不跟。
  - 周期的一切日期按制作人档案的时区算（和日程一样）。她真实的周期不存，用种子加日期现算；改档案时区最多让她整体挪一天，可以接受。
  - 周期页：玩法页加一张独立的「周期」卡和子页，**不进现在的日历**。用户的记录存服务器数据库、按用户和角色分开；页面不揭晓她真实的周期，可以像 LAPLACE 那样拿用户自己的记录比「过去估算平均差几天」。
  - 开关：部署者有总开关，用户在设置里也能关（默认开）。任何一个关着，她的言行、判断、挂断、对话事件都不受周期影响，玩法卡隐藏；记录留着，重新打开接着用。
  - 用户的记录进数据包的导出和导入，真实周期不导出；删账号时一起删。看板只加一格「记过周期的用户数」，打开时现查。上线公告写明会有周期、可以关掉；隐私政策补一句记录存在服务器上。
- 定图时查到的现状（子代理 2026-10-24）：
  - 判断题在 `backend/src/eidolon/affinity_judge.py:31-82`，开头写着「不问她的回复和档位，对所有角色一个标准」；票 03 要改这条原则。好感度常量在 `affinity.py:62-156`：`LEVEL_STEPS = (-1.5, -0.5, 0.0, 0.1, 0.2)`，不该说的话 −10，每天加分上限 `GAINS_PER_DAY = 0.6`（只限加、不限扣）；挂断、结束对话的「伤了几次」在 `affinity.py:91-128`。没有任何倍数。
  - 「此刻」由 `engine._now_prompt`（`engine.py:1074`）拼起来：`producer.now_prompt`、`today.today_lines`、`schedule.schedule_lines`；回合、通话、主动消息走同一条路（ADR 0020）。
  - 角色没有年龄字段，年龄只写在 `characters/facts/<id>.md` 第三行：果穗 12，あさひ 14，灯织、雏菜 15，16 岁 5 人，17 岁 8 人……
  - 没有按「用户 × 角色」固定的随机数先例；派生密钥的先例是 `accounts._ban_list_key`（`EIDOLON_SECRET_KEY` 加 HKDF）。
  - 对话事件现在有挂断、送礼、结束对话三种（`store.py:31`）；词汇表不让叫系统消息、通知。
  - 玩法卡在 `frontend/src/lib/playCards.ts`，子页在 `lib/playRoute.ts` 和 `play/[subpage]/page.tsx`。
- 参考：LAPLACE Cycles（<https://laplace.live/cycles>，给伴侣、家人记周期的 App，先用默认 28 / 5 天估，记满两次改用实际周期，不规律时估算变淡并说明原因），以及 <https://laplace.live/ovu>（虚拟主播的周期统计，底部有几块可展开的详情）。

- [调研：参考网站和医学资料](issues/01-reference-and-medical-research.md)：她的周期 25–34 天偏向 28–29、经期 4–7 天，成年每周期抖 ±3、未满 18 岁放宽到 ±5（不另造模型），经前 3–5 天；页面照 LAPLACE 算（一次用 28 / 5，之后取中位数，差 >7 天变淡，排卵日 = 下次前 14 天，易孕期前 5 后 1），讲七块知识、都有来源；未成年日历上画不画易孕期留给票 05。
- [拍板：她真实的周期怎么生成](issues/02-her-true-cycle.md)：不存库，纪元日加（种子, 第几个周期）的哈希逐个现算、常量冻结（ADR-0029）；基准 25–34 天按权重表抽，经期 4–7 天每次 ±1，抖动成年 ±3、`age < 18` 的 ±5，限 21–40 天，经前 3–5 天固定；种子用密钥派生的 HMAC、没密钥直接哈希；一直在走不受开关影响，只给后端用，开发模式可强制阶段。
- [拍板：好感度和挂断在经前、经期怎么变](issues/03-affinity-and-hang-up.md)：原有判断题不动，只在这几天同一请求里多问一道三档的体贴题（ADR-0030）；负档 ×2、不体贴另 −0.5、−10 不动；体贴 +0.3、单独每天 0.6 上限；警告 / 挂断阈值降到 4 / 8，不体贴记 2 分；整段一样；箭头不标、运行记录不记；补约 60 条评测集。
- [原型：她在经前、经期怎么说话，第一天的对话事件长什么样](issues/04-how-she-talks-and-first-day-event.md)：状态分天写进「此刻」（经期 1–2 天重、3 天起轻；经前剩 1–2 天重），身体小细节一次最多带一样、换着说，从不说出那个词；被直接问可以照性格半承认（经前是「快了」），成年、未成年一样；经前另有两句感受句；通话、搭话同样几行；第一天的事件写「她好像从前天起就不太舒服」（3 天以上写日期），照现有分隔线、通话层不显示，不告诉她（词汇表要开例外），经期第一个回合前记下。
- [拍板：预测怎么算、页面讲哪些知识](issues/05-predictions-and-what-the-page-teaches.md)：算法整套照 LAPLACE（含折算漏记，默认 28 / 5 不可改），推算下次经期和经前（前 5 天）、往后 3 个周期，后端现算不存；记录是第一天 + 天数、不能记未来、可改可删；平均差只和用户自己的记录比；变淡四种原因各一句；排卵日、易孕期一律只在讲解的通用示意图里；讲解收成六块（避孕拆进免责和误区），中文来源优先、逐条标注，致谢 LAPLACE；词汇表加「推算」。
- [原型：周期子页长什么样](issues/06-cycle-page-prototype.md)：一个子页，搜索框加筛选（全部 / 记过的 / 推算在经前、经期的 / 还没记过的）在一排头像条上面，下面是她的月历；电脑上右栏只放三个数字和最近 3 次记录（高度跟着月历、展开后栏里滚），讲解和免责通栏放最下；月历整格铺她的颜色加圈、推算的虚线圈、经前中性底；点一天记或改，第一天用自己画的小月历不用原生日期框；用她的颜色（DESIGN.md 要加一处）。
- [拍板：经前、经期送礼物怎么变](issues/08-gifts-during-her-period.md)：只加不减，只按医学依据算「暖的」（热可可、蜂蜜热饮，新加少见的热水袋），`gifts.toml` 加 `warm` 字段；这几天送暖的额外 +0.3、可和「她喜欢」叠加、不设上限、冷却中不额外加；给她的送礼那句多半句「心里很暖」，不暖的不加话；哪里都不提示、不留痕，开关关着照平常；不写 ADR。
- [拍板：怎么切块、开关、数据包、看板和上线](issues/07-slicing-switches-and-launch.md)：两份规格，先「她的周期」后「周期页」，各从 main 开 `feat/cycle-her`、`feat/cycle-page`，都合进 main 后一起部署；`EIDOLON_CYCLES` 默认开、后台「限额与玩法」一张卡，和好感度开关各开各的；用户开关是设置里独立的「周期」分类（账号上一列，默认开）；数据包格式 3 加可勾选的「周期记录」，重叠的留已有；看板「好感度」里一格「记过周期的用户数」；隐私、条款、配置指南、README、DESIGN.md 各改一处；合并前用线上模型重跑说话原型，部署前手动备份。

## Out of scope

- 在任何地方展示她真实的周期。
- 排卵日、易孕期影响她的言行。
- 她发的照片跟着周期变。
- 周期并进现在的日历（用户 2026-10-24 明确不要）。
- 和成就挂钩（比如「连续三次估准」）：会间接透露她真实的周期，也要多记统计；用户 2026-10-25 定不做，见[票 07](issues/07-slicing-switches-and-launch.md)。
