# 01: 酒吧的场景归一处，光顾和教程都建在它上面

**What to build:** 光顾和教程在画面上照旧这样走：

- 文本框一页页打字，点一下打完，再点翻页；
- 她的表情跟着她的台词变；
- 光顾时，她的点单句被点过去、而且她在等上酒，调酒台才开（两件事先后不限）；
- 教程时，教调酒那一节读完就开台；
- 调酒台开着时，文本框显示备忘；
- 上了酒，调酒台收起、杯子倒掉，下一句马上开始打；
- 教程按调出的那款酒说对应的反应，走完去选曲界面或店门口；
- 光顾的再试一次、重来时，清掉这次调用的台词。

这些规则现在写在光顾的画面状态里，教程绕开它的转移，直接改它的字段。这张票把文本框、她的表情、调酒台、摇酒器和备忘的规则收进新的场景 module `barScene`，开台的规则只写一处。光顾（`barVisit`）和教程（`barTutorial`）都建在它上面，各管各自特有的部分。用户看到的、听到的都不变。

背景和设计见 `../spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## 已定的设计（2026-10-27 grilling，详见 spec）

- `barScene` 是纯状态和转移，管文本框里排着的台词、正在显示的那一页和打字进度、她的表情、调酒台开没开、摇酒器、备忘。现在 `barVisit` 对外的查询（文本框此刻显示什么、开台时的备忘、谁在打字、她的嘴动不动、箭头跳不跳）都搬到这里。
- 送台词时每句可以带两样：一个标记（光顾用它记第几次调用），以及「点过去就开台」。
- 开台只有一条规则：标了「点过去就开台」的那句，最后一页被点过去，并且「可以开台」连同备忘已经给了，两样都齐了才开。开台时摇酒器清空。
- 场景还提供两样通用的转移：
  - 「上酒后收起」：调酒台收起、摇酒器清空，下一句马上显示。
  - 「清掉某个标记的台词」：清掉之后回到它们之前那一页（显示为已打完），表情也回到当时的样子。
- `barVisit` 管光顾特有的部分：
  - 店门口、进门中、再营业，以及门口的提示；
  - 这一位是谁、第几次调用；「请慢用」算进下一次调用，不跟着被清掉；
  - 重来和再试一次；出错；上酒锁定、被收下、被拒；她告别和结束卡。
  - 她的点单句带「点过去就开台」；收到 waiting 和 memo 就算「可以开台」，备忘取 memo 的内容。
- `barTutorial` 只管按节送台词、上酒后选反应、走完或跳过之后去哪，不再带光顾的状态。教调酒那一节的最后一句带「点过去就开台」，「可以开台」和这一课的备忘随这一节一起给。上酒时先让场景「上酒后收起」，再送反应。
- 共用一个分页的小函数，放在场景旁边：先载入像素字，再按她的短名（没有就用全名）和制作人的称呼分页。光顾和教程的 hook 都用它。
- 教程和光顾各自交出同一形状的「当前场景」：场景本身、此刻的时间、点、调、上。画面那一层只挑一次用哪个，去掉现在 6 处「是教程就用教程的，不然用光顾的」。
- 接口调用、会话、hook 里的那几个 ref 不归这张票，留给票 02。

## 验收

- [ ] 新的 `barScene` 照上面的设计写好，开台的规则只出现在这里。
- [ ] `barVisit`、`barTutorial` 都建在 `barScene` 上面；教程不再带光顾的状态，也不再直接改场景的字段。
- [ ] 两个 hook 改用共用的分页小函数。
- [ ] 画面那一层只挑一次「当前场景」。
- [ ] 测试：
  - `barScene` 直接测：打字、翻页；等下一句时新来的马上显示；表情；开台的两个条件，两种先后都要测；调酒台没开时调酒不起作用；上酒后收起；清掉某个标记的台词以后回到之前那一页和之前的表情；各个查询。
  - `barVisit` 的测试只留光顾特有的部分；点单句经场景开台的情况只留一条，证明两者接上了。
  - `barTutorial` 的测试只看公开的查询：备忘、箭头、文本框、走完去哪。不再断言内部字段。
- [ ] 在本地构建版上用 Playwright 验收（`docs/agents/local-acceptance.md`「酒吧」一节）：
  - 走完整个教程：开台、上酒、她的反应、去选曲界面；
  - 再走一次光顾，走到上酒、「请慢用」开始打；
  - 和改之前对照，画面一样。
- [ ] 本机跑类型检查和受影响的测试，推分支，开 draft PR，看 CI。
