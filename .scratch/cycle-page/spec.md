# 周期页：玩法页加一张「周期」卡，用户凭她的言行记下她的经期，页面替用户推算并讲清怎么算

Status: ready-for-agent

术语以 `GLOSSARY.md` 为准，特别是「周期」一节（周期、经期、经前、排卵日、易孕期、推算、体贴），以及「玩法」「日历」「角色」「制作人」「数据包」「看板」「部署者」「管理者」。说推算，不说预测；说经期、经前，不说生理期、魔法期、PMS；「安全期」只在辟谣那一条里加引号出现一次，「危险期」不用。所有决定的来历在 `.scratch/cycles/map.md` 和它的票里：参考网站和医学资料是票 01（调研在 `origin/research/cycles-reference` 的 `.scratch/cycles/research/reference-and-medical.md`），推算怎么算、页面讲什么是票 05，页面长什么样是票 06（原型 `origin/prototype/cycles-page`，`/play/cycles?variant=D` 是定稿），切块、数据包、看板和上线是票 07。

这是两份规格里的第二份，前提是「她的周期」（`.scratch/cycle-her/spec.md`）已经合进 main：周期的两个开关、账号接口的 `cycles`、设置里的「周期」分类、数据包格式 3 都已经有了。从当时的 main 开 `feat/cycle-page`，第一个提交从计划分支 `feat/cycles` 取来这份规格。两份都合进 main 以后一起部署。前端先读 `frontend/AGENTS.md` 的「shadcn 纪律」，视觉以 `DESIGN.md` 为准；给用户看的文案要少：一行说明、可展开的讲解、一行免责。讲解默认收起，是这条的例外：展开后要写得详细、严谨，深度照 LAPLACE `/ovu` 的可展开详情（用户 2026-10-25 定，见「讲解（七块）」）。

## Problem Statement

- 「她的周期」上线后，她经前、经期会不舒服、情绪起伏，体贴有回报、不体贴扣得重、她更容易挂断；可制作人没有地方记下她哪天开始的，只能凭记忆猜下一次什么时候来。
- 很多人不知道周期怎么算：以为都是 28 天、第 14 天排卵，以为推迟就是怀孕，以为「安全期」安全。这个项目的用意是普及这些常识，让人学会计算周期，也学会体贴；现在没有一页讲这些。
- 推算要讲清依据，也要说清局限：记录少、长短不一、漏记时估得不准，未成年的周期本来就不规律。用户需要知道估算为什么不准，而不是只看到一个日期。

## Solution

- **玩法页的「周期」卡**：第四张卡跟在「日历」后面，状态写「记过 n 位 · 最近 {短名} M月D日」，没记过任何人时写那行说明。两个开关任一关着时卡不出现。
- **周期子页**（`/play/cycles`，一个子页不分两级）：一行说明；对话列表同款的搜索框加筛选（全部 / 记过的 / 推算在经前、经期的 / 还没记过的）；一排可横滑的头像条，点头像换人（地址带 `?who=`）；然后是她的一块：下次经期和经前的一句话、她的月历和图例、点中那一天的一条；周期、经期、过去的估算平均差三个数和变淡的原因；最近 3 次记录（可展开全部）。电脑上月历和数字、记录左右两栏，手机上叠成一栏。最下面通栏放讲解七块（默认全收起、一次开一块），最后一行免责。
- **记一次**：点月历上的一天，「这天是第一天」打开弹窗：第一天（自己画的小月历，不用原生日期框）和天数（1–10，默认当前估计）；落在记下的经期里时「改这次」，可以改、可以删。不能记未来，记录不能重叠。记录存服务器、按用户和角色分开。
- **推算**：整套照 LAPLACE Cycles：只记一次用 28 天周期、5 天经期，标「粗略估计」；记满两次取最近至多 8 个间隔的中位数，剔除疑似漏记的、折算很长的间隔；推算下次经期和经前（下次经期前 5 天），月历往后画 3 个周期；四种情况下变淡并各说一句原因；「过去的估算平均差几天」只拿用户自己的记录比。推算在后端现算、不存库。从不揭晓、也从不和她真实的周期比。
- **排卵日、易孕期不画在任何一位的月历上**，只在「怎么算的」里放一张 28 天例子的通用示意图。
- **数据包、看板、文档**：数据包格式 3 加一类可勾选的「周期记录」；看板「好感度」分组里一格「记过周期的用户数」；隐私政策、条款、配置指南、数据包格式文档、README、`DESIGN.md` 各补一处。

## Implementation Decisions

### 记录

- **新表**（用户数据）：每行一次经期记录：记录 id、用户 id、角色 id、第一天（日历日 `YYYY-MM-DD`）、天数（1–10）、记下的时刻。不存时区：第一天就是用户当时时区下的那个日历日，改时区不挪。按用户和角色查。
- **规则**（后端检查，前端照着禁用、提示）：角色是名单上的 29 位之一；第一天不能晚于今天（制作人的有效时区：档案 → 设备 → 上海，请求带设备时区，和日程一样）；天数 1–10；同一用户同一角色的记录不能重叠（区间是第一天起的「天数」天，首尾相接不算重叠）；改一条时不和它自己比。不合规时 422 并带原因（未来、天数越界、重叠），前端照原因写一句。
- 删账号、删除全部数据时一起删；删一段对话不碰记录。开关关着时记录不删。

### 推算（新的深模块，后端，纯函数）

- 给（一位角色的全部记录, 今天）算出推算；没有记录时没有推算。和「她的周期」那个现算模块放在一起，但互不调用：推算只看用户的记录，从不读她真实的周期。不存库，每次接口读的时候现算。
- **周期长度**（照 LAPLACE，含折算漏记；默认 28 / 5 不可改）：
  1. 记录按第一天排好。只有一条时：周期 28 天，原因「只记一次」。
  2. 取最近至多 8 个间隔（相邻两条第一天之差），去掉 <15 天和 >60 天的；去掉了任何一个就记原因「可能漏记」。
  3. 锚点 = 剩下的最短间隔，夹在 22–38 天（28 的 80% 到 28 + 10）；≥ 锚点 1.6 倍的当作漏记剔除，记「可能漏记」。
  4. 只有一两个有效间隔、且都 ≥ 45 天（28 × 1.6）时：每个间隔按最接近的整数个 28 天折算（间隔 ÷ round(间隔 ÷ 28)），记「可能漏记」；出现第三个这样的间隔时不折算，当作她本来周期就长。
  5. 周期 = 剩下（或折算后）间隔的中位数，四舍五入到整天。一个可用间隔都没有（两条以上但全被去掉）时用 28，记「可能漏记」。
  6. 剩下的间隔里最长最短差 >7 天时记原因「长短不一」。
- **经期天数**：已经有可用间隔时取最近 6 条记录天数的中位数（四舍五入到整天）；还没有时取「最后一条记的天数」和 5 中较大的。
- **推算的经期**：下次第一天 = 最后一条记录的第一天 + 周期；之后每隔一个周期一次，共 3 次，每次「经期天数」天。**推算的经前**：每次推算的经期第一天之前 5 天（依据默沙东「通常于月经来潮前 5 天内」，盖住她真实的 3–5 天）。
- **过了日子**：今天晚于推算的下次第一天、还没有新记录时，记原因「这次可能还没记下」；推算照样从那一天起画 3 次，不往后挪。
- **变淡**：有任何一种原因就变淡，之后的经期、经前全部变淡（即使当前经期已经记下）。
- **过去的估算平均差**：对每个结束了的周期（第 i 条到第 i+1 条），只用前 i 条记录照上面的算法算出当时的周期，和实际间隔比，取差的绝对值；实际间隔在 15–60 天以外、或 ≥ 当时估计 1.6 倍的不比。能比的有两个及以上时给出平均值（保留一位小数，整数不带 .0）；否则没有，界面写「再记一次就能比较」之类的一句（只记一次时）。永远不和她真实的周期比。
- **今天在哪**（给筛选和状态用）：今天落在一条记下的经期里（第几天）、落在推算的经期里、落在推算的经前里，或者都不是。

下面这段类型来自票 05、06 的结论和原型的 `estimate`，接口照它（字段名可按后端习惯改）：

```ts
type Reason = "once" | "irregular" | "missed" | "late";
// once 只记一次 / irregular 长短不一 / missed 可能漏记 / late 这次可能还没记下

type Estimate = {
  cycle: number;              // 推算用的周期天数
  period: number;             // 推算用的经期天数
  reasons: Reason[];          // 空 = 不变淡
  periods: { first_day: string; days: number }[];  // 推算的 3 次经期；经前 = 每次前 5 天
  off_by: number | null;      // 过去的估算平均差，能比两个周期后才有
  today: { kind: "recorded"; day: number } | { kind: "estimated" } | { kind: "premenstrual" } | null;
};
```

  - 讲她们这些角色的设定（例如经前 3–5 天、因人而异）和讲医学事实分开；医学事实不拿我们的设定当依据。
  - 引用原文用词时（「经前综合征」「痛经」「月经过多」）照原文；我们自己的话守词汇表。

  1. **怎么算的**
     - 导语：推算只看你记下的日期，按下面几步算；它能告诉你大概哪天，不能告诉你她身体里发生了什么。
     - 周期从经期第一天算到下次经期第一天的前一天。［NHS <https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/>；默沙东大众版「月经周期」<https://www.msdmanuals.cn/home/women-s-health-issues/biology-of-the-female-reproductive-system/menstrual-cycle>］
     - 只记一次时，周期按 28 天、经期按 5 天粗略估计：28 天是人群周期的中位数，5 天是通常的经期天数。［LAPLACE Cycles「How Predictions Work」<https://laplace.live/cycles/predictions?locale=en>；默沙东专业版「女性生殖内分泌学」；NHS］
     - 记满两次后，取最近至多 8 个周期长度的中位数；用中位数，是为了不被一次特别长或特别短的周期带偏。短于 15 天、长于 60 天的先去掉，长到最短那个 1.6 倍以上的当作中间漏记了一次，不算进去（一段很长的空档不能证明中间没来过）。经期天数取最近 6 次的中位数。［LAPLACE Cycles］
     - 什么时候变淡：只记了一次；最长和最短的周期差 7 天以上（和中国指南「规律月经」的界线一样）；有疑似漏记被剔掉；或者到了推算的日子还没记新的。［LAPLACE Cycles；中国 AUB 指南 2022］
     - 「过去的估算平均差」：对每个已经结束的周期，只用它开始之前的记录重算一遍当时的推算，看下次经期实际早晚了几天，再取平均。［LAPLACE Cycles］
     - 示意图：28 天的例子，标出经期、排卵日（下次经期第一天往前数 14 天）、易孕期（排卵日前 5 天到后 1 天）。［默沙东专业版「基于生育意识的避孕方法」<https://www.msdmanuals.cn/professional/gynecology-and-obstetrics/family-planning/fertility-awareness-based-methods-of-contraception>；默沙东大众版「月经周期」］
     - 「减 14」只是近似：排卵到下次经期（黄体期）实测平均约 12.4 天，个体之间差约 2 天［Bull 2019 <https://www.nature.com/articles/s41746-019-0152-7>；Fehring 2006 <https://epublications.marquette.edu/nursing_fac/11/>］；28 天的周期里，正好在下次经期前 14 天排卵的只有约 10%［Wilcox 2000 <https://www.bmj.com/content/321/7271/1259>］。所以示意图上的排卵日、易孕期只是讲道理用的例子。
     - 算法参考 LAPLACE Cycles。［<https://laplace.live/cycles>］
  2. **基础知识**
     - 导语：一个周期里身体在做什么，多长算正常，为什么每个人、每次都不一样。
     - 一个周期分经期、卵泡期、排卵、黄体期。经期出血是子宫内膜脱落排出；卵泡期卵泡发育、内膜重新长厚；排卵时卵巢排出一个卵子；黄体期激素让内膜准备好，没有怀孕就回落，下一次经期开始。［默沙东大众版「月经周期」］
     - 周期长短的差异主要来自卵泡期，黄体期相对稳定。［默沙东大众版「月经周期」；Bull 2019］
     - 中国指南：周期 21–35 天（28±7 天）属于正常，近一年最长最短差不到 7 天算规律。［中国 AUB 指南 2022，经丁香园转载 <https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g>］
     - 经期一般 2–7 天，通常约 5 天，出血前两天最多；中国指南以不超过 7 天为正常。一次经期平均失血约 30 mL（5–80 mL）。［NHS <https://www.nhs.uk/conditions/periods/>；中国 AUB 指南 2022；默沙东专业版「女性生殖内分泌学」<https://www.msdmanuals.cn/professional/gynecology-and-obstetrics/female-reproductive-endocrinology/female-reproductive-endocrinology>］
     - 对 12 万名 App 用户的统计里，只有约 13% 的周期正好 28 天；同一个人每次也会差几天。［Bull 2019；Fehring 2006］
     - 易孕期为什么有好几天：卵子排出后大约 12 小时内能受精，精子在体内能存活 3–5 天，所以排卵前几天到排卵当天都可能怀孕，一个周期里大约 6 天。［默沙东大众版「月经周期」；Wilcox 2000］
  3. **青春期**
     - 导语：刚开始来月经的几年，周期不规律是正常的。
     - 中国汉族女孩初潮的中位年龄 2019 年是 12.0 岁，也就是 12 岁的女孩里大约一半已经来过。［Ma 2023，doi:10.1007/s12519-023-00723-9］
     - 为什么不规律：控制排卵的激素系统（下丘脑—垂体—卵巢）还没成熟，头一两年很多周期不排卵。［中华医学会科普 2022-07 <https://www.cma.org.cn/art/2022/7/30/art_4584_46755.html>；Shaw 综述 PMC6570576］
     - 初潮后第一年不规律是正常的过渡；初潮后 1–3 年内，周期 21–45 天都还算正常。［中国青春期 AUB 共识 2024 <https://gocm.bmj.com/content/5/1/e000115>；ACOG CO 651 <https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2015/12/menstruation-in-girls-and-adolescents-using-the-menstrual-cycle-as-a-vital-sign>］
     - 通常初潮后两三年规律才逐渐建立，有的要到五年。［中华医学会科普 2022-07；默沙东大众版「青春期」<https://www.msdmanuals.cn/home/women-s-health-issues/biology-of-the-female-reproductive-system/puberty-in-girls>］
     - 该看医生的情况：15 岁还没来；哪怕一次间隔超过 90 天；经期超过 7 天；1–2 小时就要换一片卫生巾。［ACOG CO 651；中国青春期 AUB 共识 2024］
  4. **经前和经期**
     - 导语：经前几天和经期常有哪些不适，为什么会有，多久会好。
     - 经前几天可能易怒、焦虑、低落、睡不好、注意力不集中，身体上可能乳房胀痛、腹胀、浮肿；通常在月经开始后几小时到几天内消退。轻重因人而异，每个周期也不一样。［默沙东大众版「经前综合征」<https://www.msdmanuals.cn/home/women-s-health-issues/menstrual-disorders-and-abnormal-uterine-bleeding/premenstrual-syndrome-pms>；中华医学会科普 2022-12 <https://www.cma.org.cn/art/2022/12/19/art_4584_48741.html>］
     - 为什么：和黄体期激素的起落有关，确切机制还不完全清楚。［默沙东大众版「经前综合征」］
     - 经期可能下腹痛、腰酸、头痛、恶心、疲倦；疼痛在开始后 24 小时左右最重，两三天后缓解。疼痛来自子宫收缩，和内膜释放的前列腺素有关。［默沙东大众版「痛经」<https://www.msdmanuals.cn/home/women-s-health-issues/menstrual-disorders-and-abnormal-uterine-bleeding/menstrual-cramps>］
     - 痛经会影响约三成或更多女性的日常活动；原发性痛经多从青春期开始。［默沙东大众版「痛经」］
     - 疼得影响生活、突然剧痛、持续疼痛或发热，要尽快看医生。［默沙东大众版「痛经」］
  5. **常见健康问题**（新加，学 /ovu「健康问题」）
     - 导语：下面是和经期有关的几种常见问题，不是完整清单，也不能用来自我诊断。担心自己或身边的人时，可以记下每次经期和症状，看妇科时带给医生。
     - 每一种照同一个顺序写两三句：是什么；常见表现；怎么诊断、怎么治（一句带过）；大约多常见（说清是什么人群、哪个来源）；什么时候要看医生。
     - 条目：经前综合征；经前烦躁障碍（经前综合征的严重形式，影响正常生活）；痛经（原发和继发）；月经过多（1–2 小时就浸透一片、有大血块、经期超过 7 天）；多囊卵巢综合征；子宫内膜异位症；子宫肌瘤；卵巢囊肿破裂或扭转（突发剧烈腹痛、发热、恶心，要立刻就医）。
     - 来源：默沙东中文版（大众版优先）对应各章，实现票里逐条补查链接；发生率只用能追到出处的数，追不到就不写数。/ovu 的数（PMS 约 90%、PMDD 2–5% 等）没有出处，不照搬。
  6. **怎么体贴**
     - 导语：知道她这几天可能不舒服以后，能做什么、不该做什么。
     - 让她多休息、睡够；热敷下腹、适当活动能缓解痛经。［默沙东大众版「痛经」］
     - 经前少糖、少盐、少咖啡因，多运动有帮助。［默沙东大众版「经前综合征」］
     - 疼得厉害时，非处方的止痛药（如布洛芬）按说明服用能缓解；吃了也不见好就该看医生。［默沙东大众版「痛经」］
     - 她不想说就别追问，也不把她的情绪归到「那几天」上。［LAPLACE /ovu「概述与规则」<https://laplace.live/ovu>］
  7. **常见误区**（每条 ❌ 开头，下面一两句讲为什么不对）
     - ❌ 住在一起月经会同步：追踪一年多的研究没有发现同步；最早报道同步的研究重新分析后是偶然，周期本身的波动会让经期时而靠近、时而分开，看起来像同步。［Yang & Schank 2006，doi:10.1007/s12110-006-1005-z］
     - ❌ 周期都是 28 天、第 14 天排卵：只有约 13% 的周期正好 28 天；28 天的周期里最常见的排卵日是第 16 天。［Bull 2019；Johnson 2018 <https://www.tandfonline.com/doi/full/10.1080/03007995.2018.1475348>］
     - ❌ 推迟就是怀孕：压力、体重变化、运动过度都会让周期推迟；推算也判断不了是否怀孕。［默沙东大众版「月经周期停止」<https://www.msdmanuals.cn/home/women-s-health-issues/menstrual-disorders-and-abnormal-uterine-bleeding/absence-of-menstrual-periods>］
     - ❌「安全期」是安全的：排卵会受压力、作息影响提前或推迟；只靠日历推算，常规使用一年约 12/100 会怀孕。［WHO《计划生育：全球服务提供者手册》2022 第 18 章 <https://www.fphandbook.org/sites/default/files/JHU%20HBk22%20-%20Chapter%2018.pdf>；广东省疾控 <https://cdcp.gd.gov.cn/zzzq/jkts/content/post_4779475.html>］
     - ❌ 记录周期只是为了备孕或避孕：医生把月经周期当作和体温、血压一样的健康指标，记下来能及早发现异常（学 /ovu「只有有性生活的女性才会记录周期」那条）。［ACOG CO 651］
- 「安全期」只在误区那一条加引号出现一次；「危险期」不用；日历法 14.4%–47% 那个数没追到原始研究，不用。
- **示意图**：一条 28 格的横条（不代入任何一位的数据），照算法标：经期第 1–5 天，下次经期第一天是第 29 天，往前数 14 天的排卵日落在第 15 天，易孕期是它前 5 天到后 1 天的第 10–16 天（讲解文字里提到第几天时和图对上，误区那条的「第 14 天」是大众的说法），用中性色和一处强调色（不用她的颜色，它不属于哪一位），下面一行说明「以 28 天为例」。
- **免责**一行（Meta 字号，页面最后）：「推算只是估计，不是医疗建议，不能用来避孕；身体不适请看医生。」

## Testing Decisions

- 只测对外的行为：接口给了什么、拒绝了什么、推算的结果、库里留没留下东西、数据包里有什么、看板上的数；不测组件、不测推算内部的中间值。
- **推算直接测纯函数**（这份规格唯一新开的直接测的模块，照 LAPLACE 逐条）：
  - 没有记录没有推算；只记一次 28 / 5（记的天数大于 5 时用记的）并有「只记一次」。
  - 规律的十几条：中位数、最近 8 个间隔为限、最近 6 次的经期中位数、不变淡、平均差。
  - <15、>60 的间隔被去掉并记「可能漏记」；≥ 锚点 1.6 倍的被剔除；锚点夹在 22–38。
  - 一两个都 ≥ 45 的间隔被折算（56 → 28、84 → 28、50 → 25）；第三个这样的间隔出现后不折算、周期就是长的。
  - 最长最短差 7 不变淡、8 变淡。
  - 过了推算的日子记「这次可能还没记下」、推算不往后挪；推算日子当天还不算过了。
  - 平均差：少于两个能比的没有；15–60 以外和 ≥ 当时估计 1.6 倍的不比；只用当时之前的记录。
  - 推算 3 次经期、每次前 5 天经前；今天在哪的四种情形。
- **后端走现有的 HTTP 接缝**（`make_client` 加 `FakeClock`；档案接口设时区；库里的东西照现有做法用 sqlite 直接查）：
  - 记、改、删：合法的存下并返回更新的推算；未来（按档案时区，比如 `Pacific/Auckland` 的今天比上海早一天到）、天数 0 和 11、重叠、首尾相接不算重叠、改成和别的重叠、不认识的角色、别人的记录，各自的状态码和原因。
  - 读：29 位、顺序照名单、没记过的推算为 null；接口里没有她真实周期的任何东西（和「她的周期」的纯函数对照：换一个她真实周期完全不同的种子，接口返回不变）。
  - 开关：部署者关或用户关时读返回「没开」、写 409；关了再开记录还在。先例：`test_schedule_switch.py`、`test_reach_out_switch.py`。
  - 数据：删账号后记录表不剩这位用户的行（`test_database.py` 登记新表）；删一段对话后记录还在。先例：`test_delete_account.py`。
  - 数据包：勾了「周期记录」时导出有记录、没勾没有；导入并进、重叠的跳过留已有、不认识的角色跳过、未来的跳过；开关关着也能导出导入；格式 2 的包照旧能导入。先例：`test_data_package.py`、`test_data_package_reach_outs.py`。
  - 看板：那一格是有记录的用户数（一个用户记多位只算一次），不跟时间范围，关着时为 null；好感度关着、周期开着时「好感度」那组照样有这一格。先例：`test_schedule_dashboard.py`、`test_affinity_dashboard.py`。
- **前端只测 `lib/` 里的纯函数**：
  - 新的 `lib/cycles`：月历一个月每格的记号（记下 / 推算的经期 / 推算的经前 / 没有，记下盖过推算，变淡）；「经前」字样只落在每段经前的第一天；筛选四类和每类的人数、选中的她留在条里、搜索时不看筛选；她那一句话的各种情形；点中那一天的那条和右端按钮（第一天 / 改这次 / 不能记未来）；记录列表的「隔 n 天」和展开（3 次、只多 1 次时全露）；弹窗的默认天数、−/+ 夹在 1–10；小月历今天以后不能选；`?who=` 的解析（没带、不认识回到第一位）。
  - `playCards`：第四张卡的出现条件和状态（没记过时那行说明、「记过 n 位 · 最近…」的「最近」怎么挑、都过了日子时）；`playRoute`：子页多一个 `cycles`、关着时回到 `/play`。
  - `dataPackage`：勾选项多一类；`dashboard`：那一格和「好感度」标签的显示条件。
- **验收**（`docs/agents/local-acceptance.md`，本地构建版、Playwright）：电脑和手机两种宽度下的版式；搜索和四种筛选；头像条换人、`?who=` 刷新还在；点一天、记一次、改一次、删一次，推算和卡片状态跟着变；未来的日子不能记；小月历；变淡的几种情形（用接口造记录）；讲解七块一次开一块、来源链接能开；关掉周期后卡和子页消失、再开记录还在；数据包勾「周期记录」导出再导入。能用接口造的自己造，只把要人看的（版式好不好看、讲解措辞）留给用户。

## Out of Scope

- 她真实的周期怎么生成、她怎么说话、好感度和挂断、第一天的对话事件、开关本身：都在「她的周期」那份规格里。
- 在任何地方揭晓她真实的周期，或拿用户的记录和它比。
- 在任何一位的月历上画排卵日、易孕期；为哪位角色推算排卵日、易孕期。
- 让用户改默认的 28 / 5 天。
- 记未来的经期、记症状、记经量、提醒和通知。
- 周期并进现在的日历；周期页和对话列表的「隐藏」相通；筛选存在设备上。
- 和成就挂钩（会间接透露她真实的周期，也要多记统计）。
- 别的语言的讲解：讲解只写中文（界面本来只有中文）。
