# LAPLACE /ovu 可展开详情的结构（2026-10-25 读）

来源：<https://laplace.live/ovu> 页面底部四个手风琴按钮，用 Playwright 打开、逐个点开读的（第一次进会被 Vercel 安全检查挡几秒）。它自己写明「翻译并改编自 ovu.moe」。这里只记结构、写法和要点，供周期页讲解（`spec.md`「讲解（七块）」）对照深度；不照搬原文，我们的每个事实另按调研的来源标注。

## 整体写法

- 每块开头先交代来源和用意，再说「不构成医疗建议」；正文是一段一两句的短段落，一块 6–30 段不等。
- 先讲是什么，再讲为什么（机制），最后讲多常见、该怎么办。
- 来源只在每块开头笼统交代，不逐条引用，所以有几处数字和说法不严谨（见末尾）。
- 第一人称、口语、带自嘲（我们不学）。

## 四块

1. **概述与规则**：用意（「让对此一无所知的 VTuber 粉丝快速入门，而非提供医疗建议」），推荐去加州大学戴维斯分校妇产科网站了解详情；十几条使用规则（不人肉、满 18 岁、「除非她们主动提起，否则不要当面对她们谈论她们的生理周期」、「友善一点」等）；常见问答三问（为什么做、隐私、预测准不准：「算法非常简单，可用数据既稀疏又嘈杂」）。
2. **基础知识**，7 段：个体差异大、同一个人每次也不同；激素周期性波动，四个阶段月经期 → 卵泡期 → 排卵期 → 黄体期；周期从月经期第一天开始，出血是子宫内膜脱落；排卵在周期中段、约 1–2 天，可用基础体温判断；精子能存活一段时间所以易孕期有好几天；卵泡期往往情绪较好、不太疼；黄体期激素升高，可能引起经前的疼痛和负面情绪。
3. **健康问题**，开头：信息取自 hopkinsmedicine.org 和 health.ucdavis.edu，「这并不是一份完整的清单」；「每位女性的症状与体验都不一样」；建议记录月经及症状日记，看妇产科时带给医生。之后八种，每种四五段，大致按「病因和治疗 → 怎么诊断 → 症状 → 是什么 → 发生率」：
   - 经前综合征（PMS）：经前出现身体和情绪症状、经期开始后消退；诊断要连续几个月记症状日记；无根治、靠生活方式和药物；焦虑、背痛、头痛、乳房胀痛、注意力不集中、便秘或腹泻；写「约 90%」。
   - 经前烦躁障碍（PMDD）：PMS 的严重形式，影响正常生活；抑郁、无价值感、情绪波动等，也有身体症状；写「约 2–5%」。
   - 多囊卵巢综合征（PCOS）：需检查诊断；疼痛、生育力下降，有时不排卵、卵巢形成囊；写「约 5–15%」。
   - 子宫内膜异位症：内膜样组织长在子宫外，造成炎症、瘢痕、囊肿；疼痛、经量多或不规律、非经期点滴出血、不孕等；诊断常需小手术，超声或 MRI 有时能看到；写「约 2–10%」。
   - 卵巢囊肿破裂（或扭转）：突发剧烈腹痛、发热、恶心，必须立即就医。
   - 子宫肌瘤：子宫里的非癌性肿瘤，常在体检或影像检查中发现，多数不用治；经量多、经期长、经间期出血、压迫感；写「约 20–50%」。
   - 月经过多：激素失衡、其他疾病、妊娠相关、宫内节育器等；出血时间长，1–2 小时浸透一片卫生巾或棉条，经间期出血，大血块；写「约 20%」。
   - 痛经：原发（体内化学物质失衡）和继发（其他疾病）；下腹、下背或腿部剧烈痉挛，可伴恶心、呕吐、腹泻、昏厥、头痛；写「约 60% 轻微痉挛，5–15% 严重到影响日常」。
4. **常见误区**，开头说这些流言最初或许是玩梗，但有人会当真；四条，每条 ❌ 开头、下面一两段：月经会同步（最初的研究已被推翻）；避孕措施只供有性生活的女性使用（也有人用激素避孕缓解严重经痛等）；只有有性生活的女性才会记录周期（记录周期是健康管理的一环，也方便提前安排）；月经没来或推迟就代表怀孕（激素受压力、饮食、环境影响）。

## 它不严谨、我们不照搬的地方

- 出血「可能持续几天到两周」：中国指南以经期不超过 7 天为正常，超过 7 天是经期延长。
- 精子「可以在体内存活约一周」：默沙东写 3–5 天。
- 各病的发生率没有逐条出处（「来自多个网站」），PMS「约 90%」这类数要追到原始来源才能用，追不到就不写数。
- 排卵期写「约 1–2 天」：默沙东写排卵期 16–32 小时，卵子排出后约 12 小时内可受精。
