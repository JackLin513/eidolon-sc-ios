# 04: 数据包「周期记录」和看板那一格

**What to build:** 用户导出数据包时能勾选带走周期记录，导入时这些记录并进已有的；管理者在看板上看到有多少用户记过周期。

**数据包**：「她的周期」已经把格式升到 3，这张票在同一个格式 3 里加一类可勾选的「周期记录」（`cycles`）。
- 位置：排在对话、照片、记忆、档案后面；导出页的勾选项照现有几类的写法。
- 每条只有三样：角色 id、第一天、天数。不导出记录 id 和记下的时刻，也不导出任何推算或她真实的周期。
- 导入时并进已有记录，按条检查，下面几种跳过：
  - 角色不在这个部署的名单上
  - 天数越界
  - 第一天晚于导入时的今天
  - 和这位角色已有的记录重叠，包括这次导入里已经并进去的；重叠时留已有的
- 导入结果照现有几类，给出导入几条、跳过几条。
- 开关关着时也能导出、导入。
- `docs/data-package-format.md` 写上格式 3 的「周期记录」。

**看板**：「好感度」分组里加一小节「周期」，只有一格「记过周期的用户数」。
- 数的是现在库里至少有一条记录的用户。
- 不跟时间范围走，打开看板时直接查表。
- 部署者关着周期时这一格为 null，不显示。
- 看板标签的显示条件要带上它：好感度关着、周期开着时，「好感度」分组照样出现，里面只有这一格。
- 不加运行记录、汇总行、遥测。
