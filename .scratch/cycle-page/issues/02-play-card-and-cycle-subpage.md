# 02: 玩法卡和周期子页：选人、月历、数字、记改删

**What to build:** 玩法页多一张「周期」卡。点进去能挑一位角色，在她的月历上记下、改、删一次经期，并看到推算的下次经期、经前和三个数字。讲解和免责先留好位置，内容在票 03。

**玩法卡**：
- 卡片注册表加第四张 `cycles`（「周期」），跟在「日历」后面；子页列表加 `cycles`。
- 图标 Lucide `CalendarHeart`，中性色。
- 只在 `GET /api/cycles` 返回开着时出现。读到之前不闪出又消失，照日历卡的写法。
- 状态：没记过任何人时写那行说明。记过时写「记过 n 位 · 最近 {短名} M月D日」：「最近」是推算的下一次第一天不早于今天、且最早的那位；都过了日子时取最早的那位。
- 两个开关任一关着时，`/play/cycles` 回到 `/play`。

**子页**照规格「周期子页（版式 D）」，从上到下：
1. 一行说明。
2. 对话列表同款的搜索框，用同一套名字和组合的匹配。
3. 筛选：电脑上是 Popover，手机上是 Drawer。标题「头像条里显示谁」，四类单选，每类后面写「n 位」；不是「全部」时按钮上有一个中性小点。搜索时不看筛选；选中的她一直留在条里；筛选只存在页面状态里。
4. 头像条：48px 头像加短名，选中的铺 `bg-muted`。地址带 `?who=`，换人时替换历史；没带或不认识时选第一位。
5. 她的那一块，注入她的颜色变量。电脑（≥ 768px）左右两栏，右栏 15rem，高度跟着左栏；手机上叠成一栏。
   - 左栏：她那一句话（各种情形见规格）、月历、图例、点中那一天的一条。
   - 月历：一个月一页，能翻前后月，周一在前。
     - 记下的经期：整格铺 `--her-wall`，日期外一圈 2px `--her-mark`。
     - 推算的经期：日期外一圈虚线 `--her-mark`。
     - 推算的经前：整格铺 `bg-muted/60`，每段第一天的格子底部写「经前」（只在电脑上）。
     - 变淡时推算的记号 `opacity-50`；记下的盖过推算的。
     - 今天和选中的格子照日历子页。不画排卵日、易孕期。
   - 点中那一天的一条：右端是「这天是第一天」、「不能记未来」或「改这次」；没点时写那句提示。
   - 右栏：周期、经期、过去的估算平均差三行（只记一次时标粗略估计）；变淡原因每种一句；「记过的经期」新的在上，每行写第一天和「n 天 · 隔 n 天」，右端一个铅笔。只露 3 次（只多 1 次时全露），下面「展开全部 n 次 / 收起」，展开后在栏里滚。
6. 讲解和免责的位置（内容在票 03）。

**弹窗**：
- 标题「记{角色名}的一次经期」。
- 第一天：一个 outline 按钮，写着「2026年10月25日 周日」，点开自己画的小月历（周一在前、今天以后不能选），**不用原生日期框**。从「这天是第一天」打开时预填那一天。
- 天数：−/+ 夹着「n 天」，1–10，记新的时默认推算的经期天数（没记过为 5）。
- primary 用她的颜色。改的时候左下多一个「删除这次」，不二次确认。
- 服务器退回时在弹窗里写一句原因。
- 成功后用返回的记录和推算换掉这一位的数据，卡的状态也跟着变。

照 shadcn 纪律，用现有组件（Popover、Drawer、Dialog、Button），视觉以 `DESIGN.md` 为准，文案要少。见规格「玩法页的卡」「周期子页」「她的颜色」和 Testing Decisions。

**模块**
- `frontend/src/lib/cycles.ts`：接口类型（`Her`、`CycleEstimate`、`CyclesView`）和读、记、改、删四个请求，以及子页、卡用到的纯函数：
  - 月历每格的记号 `monthMarks`
  - 筛选 `CYCLE_FILTERS`、`filterCounts`、`stripOf`
  - 一句话 `herLine`
  - 点中那天的一条 `dayBar`
  - 记录列表 `shownRecords`
  - 弹窗 `defaultDays`、`clampDays`、`isPickable`、`canShowNextMonth`、`fullDate`
  - `?who=` 的 `cyclesWho`
  - 卡的「最近」`soonest`
- `lib/playCards`：第四张卡 `cycles`。`PlayContext.cycles` 在关着或还没读到时为 null，卡就不出现，读到之前不会闪出来。
- `lib/playRoute`：`PLAY_SUBPAGES` 加 `cycles`；新的 `closedPlayRedirect(subpage, { cyclesOn })`。
- `components/play/useCycles.ts`：读 `GET /api/cycles`。`components/play/CyclesSubpage.tsx`：子页和弹窗。
- 图标 `CyclesCardIcon`（CalendarHeart）、`EditRecordIcon`、`FewerDaysIcon`、`MoreDaysIcon`。`ui/button` 加了 `ghost-destructive` 变体，给「删除这次」用。

**实现中自己定的几处**
- 关着时回到 `/play` 在客户端做：proxy 不知道开关，子页读到 `{"enabled": false}` 就 `router.replace("/play")`。写的时候遇到 409，也当作关着处理。
- 她的颜色只注入月历格子、图例和弹窗，不注入整块。所以「这天是第一天」是中性的 default 键（审查里发现原来是她颜色的实底，超出了规格列的三处）。小月历里选中的日子铺中性 `bg-muted`。
- 变淡时推算的经前铺 `bg-muted/30`，没有给整格加 `opacity-50`，免得日期数字也跟着淡下去。虚线圈改成 `outline-her-mark/50`。
- 没记过的那位，右栏三行写「—」。平均差为 null 时写「再记一次就能比较」，不论是只记了一次还是只有一个间隔。
- 「最近」照规格取每位推算的下一次（`periods[0]`）。她那句话里的「下次」取今天以后的第一次，过了日子时那句改写「推算 M月D日 来，还没记下」。
- 「改这次」的弹窗标题和记新的时一样，都是「记{角色名}的一次经期」，照票写的。

**审查里属于判断题、没改的**
- 月历的页首、星期头和格子外壳，和日历子页的 `MonthView` 差不多；筛选键的骨架和对话列表的 `ListFilter` 也一样，搜索框是照抄的。可以抽成项目组件（「月历」「筛选键」），但要动日历子页和对话列表，留到以后。
- `Her` 这个名字太泛（指一位的记录加推算），和票 01 的接口说明一致，没改。
- 「删除这次」带了垃圾桶图标，规格没提。
