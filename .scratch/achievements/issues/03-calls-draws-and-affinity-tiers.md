# 03: 其余几处进度：通话时长、抽奖次数、好感度档位

**What to build:** 剩下三样也记进成就。接通过的通话挂断结算后，她的通话累计时长加上这次的时长；抽奖抽了几次「抽过几次奖」就加几次，抽到第 10、50…次时抽奖接口的返回里带着这次到账；回合和送礼之后看她现在的好感度档位，到过亲近、亲密的阶段解锁，掉下来也不收回；「到过亲密的有几位」由按角色的档位推出来。见规格「记进度：接在往来记账上」的「通话结束了」「抽过奖了」「档位」，和「到账了什么」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 往来记账加「通话结束了」：只有接通过的通话；放在通话结算、通话记录写进库以后（`CallOutcome` 的 `keep`），那里要能拿到用户和角色；没有响应可带回，靠 `rewarded_at` 和轮询
- [ ] 往来记账加「抽过奖了」：放在 `Gifts.draw` 提交、放开礼物模块的锁以后调（锁不可重入）；抽一次、全部抽完都按次数累计；抽奖接口的返回带「这次到账」
- [ ] 档位：回合和送礼之后取变化后的档位，到了亲近算到过亲近，到了亲密两个阶段都算；存到过的最高档位；不挂在好感度模块内部，自然恢复、重置卡两处不用看
- [ ] 「到过亲密的有几位」由档位到过亲密的角色数推出来，不另存
- [ ] 开关关着不记；出错只记日志、不让通话结算或抽奖失败
- [ ] 后端测试：通话只有接通的算、累计、跨阶段（照 `test_call_stats.py` 的通话驱动）；抽奖次数累计、抽奖返回带着解锁（照 `test_gift_draws.py`）；档位到过亲近、直接到亲密两个都解锁、掉下来不收回（假判断的升降推档位，照 `test_affinity_turns.py`）；到过亲密的有几位；集齐需要四个成就都走完（这张票以后档位和通话才可能集齐）
