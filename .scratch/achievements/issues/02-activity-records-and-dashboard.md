# 02: 运行记录和看板「每日任务和成就」三格

**What to build:** 管理者在看板上看得到成就发出了多少东西。每解锁一个成就阶段、每集齐一位角色，运行记录里留一条；看板「每日任务」那一小节改名「每日任务和成就」，多出三格：解锁的阶段（个）、发出的抽奖次数、重置卡（张）。这些记录不算进回合数、活跃用户和趋势。见规格「运行记录和看板」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 运行记录加一种 `kind`：解锁一个成就阶段；哪个成就第几阶段放进 `result`，角色放进 `character_id`（合起来的为空）；集齐也记一条同一种 `kind`、`result` 标成集齐；沿用 `record_rollups` 现有的列
- [ ] 到账成功后写，写失败只记日志；同一阶段只写一条（只在真到账时写）；上线补算不写（补算的路径在票 04，这里留好不写的口子）
- [ ] 看板别的小节排除这种记录：回合数、活跃用户、趋势不变（同每日任务那种）
- [ ] 看板那一小节标题改「每日任务和成就」，加三格：解锁的阶段、发出的抽奖次数（按阶段序号加起来）、重置卡（集齐的条数）；小节什么时候出现照每日任务现在的规则
- [ ] 管理者只看得到合计，看不到某一位用户的成就
- [ ] 后端测试：三格的数、集齐的条数、别的小节的数不变（照 `test_affinity_dashboard.py`、`test_activity_records.py`）
- [ ] 前端测试：看板那一小节（`dashboard.test.ts`）
- [ ] 本地构建版上用 Playwright 看一眼看板那一小节
