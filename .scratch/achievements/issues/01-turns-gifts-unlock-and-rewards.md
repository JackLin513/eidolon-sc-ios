# 01: 走通：回合和送礼记成就进度、解锁、到账，接口看得到

**What to build:** 成就从头走通。用户和一位角色有回合（打字的和通话里的都算）、送出礼物时，「和她的回合数」「送她的礼物件数」「来过几天」随之前进，「往来过几位角色」由按角色的进度推出来；过了门槛的阶段自动解锁，第 n 阶段到账 n 次抽奖；她按角色算的四个成就全部解锁时算集齐，另给 1 张重置卡，每位角色一辈子只给一次。回合 `done` 和送礼返回里的「这次到账」带上解锁了哪些阶段、集齐了哪位；她的成就和合起来的成就从接口看得到。这张票还建好前端两处都要用的「每一行写什么」纯函数。见规格「先对照 main」「八个成就（常量）」「记进度：接在往来记账上」「存什么」「到账了什么」「接口」，以及「她的对话页」里每一行的写法。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 开工先读 main 上每日任务做出的往来记账、发奖励入口、「这次到账」、`GET /api/gifts` 的 `rewarded_at`；和规格对不上的地方记进本票 `## Comments`
- [ ] 八个成就的门槛和每阶段的奖励都写成常量（第 n 阶段 n 次抽奖），集齐给 1 张重置卡也是常量；阶段按序号认
- [ ] 成就进度表（用户、成就、角色一行累计数，合起来的角色为空；「来过几天」带最后一天）和解锁的阶段表（用户、成就、角色、第几阶段唯一，带解锁时刻）；都登记进 `USER_DATA`，不进数据包
- [ ] 往来记账里加成就一份：回合记下了加她的回合数，送礼了加她的件数，两处都在北京时间新的一天时给「来过几天」加一（按注入的时钟）；「往来过几位」由回合数至少 1 的角色数推出来，不另存
- [ ] 每次记进度后按当前门槛解锁没解锁过的阶段、到账，再看这位角色是否集齐；进度写入、解锁、到账记录、余额修改在同一个事务里；到账键形如「成就、角色、第几阶段」和「集齐、角色」，同一阶段只到账一次、每位角色重置卡只有一次
- [ ] 一次跨过几个阶段时几个都解锁、都到账；门槛调低后下一次相关动作时解锁；调高、删阶段不收回；加了阶段后再集齐不给第二张重置卡
- [ ] 开关关着时什么也不记；出错只记日志、不让回合或送礼失败；删历史对话、导入数据包都不经过它
- [ ] 「这次到账」加上解锁的阶段（成就、角色、第几阶段、给了几次抽奖）和集齐的角色（给了几张重置卡）；打字回合、通话里回合的 `done` 和送礼返回都带着
- [ ] 新增 `GET /api/characters/{id}/achievements`：她的四个成就（累计进度、各阶段门槛和奖励、已解锁阶段的解锁时刻）和集齐那一行；档位只给档位名；开关关着时返回 null
- [ ] `GET /api/gifts` 加 `achievements`：合起来的四个，形状同上；开关关着时为 null
- [ ] 成就到账照常更新 `rewarded_at`（导航「礼物」上的点照旧亮）
- [ ] 前端 `lib/` 纯函数：每一行写什么（名字、阶段点、下一个阶段的进度文字、全部解锁、下一阶段的奖励「抽奖 ×n」），各类进度文字（回合、时长「3 小时 12 分 / 5 小时」、件数、档位「下一个：亲密」、位、天、次），「集齐」一行；名字照原型 `?ac=B`；类型照接口的形状
- [ ] 后端测试（走 HTTP 接口，`FakeClock`）：回合和送礼各自解锁的时机、第 n 阶段给 n 次；一次跨几个阶段；集齐给重置卡只一次（monkeypatch 降门槛）；门槛调低、调高；通话里的回合算；来过几天同一天只算一天、跨北京时间 0 点算两天、不要求连续；往来过几位推出来；隐藏的角色照样记；开关关着不记、接口 null；删历史对话不倒退；导入数据包不前进；两个并发回合只到账一次；删除用户后新表不剩行
- [ ] 前端测试：行写法函数的各种情况
