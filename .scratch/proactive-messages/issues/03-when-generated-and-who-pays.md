# 03: 拍板：什么时候生成、用谁的模型、谁付钱

Type: grilling
Status: open
Blocked by: 02

## Question

主动消息什么时候真正生成出来，用哪个模型，钱算谁的：

- 到点生成：服务器的后台循环到了时间就生成、写进对话。这时用户多半不在线，服务器手里没有他的自带密钥，只能用部署者的模型（对话模型还是后台模型）。
- 回来时补上：用户下次打开网站时，才补上他不在的这段时间里她「发来」的话。那时浏览器在线，自带 LLM 的用户可以用自己的 key；不再回来的用户不花一分钱。但要定补上的显示成什么时间（真实生成的时间，还是假装是之前发的），以及补上要不要让用户等。
- 两者混合：用户在线时到点生成、离线时回来补上。
- 很久没来的用户：到点生成的话，多久不来就不再给他生成。
- 计不计入用户的限额、走不走免限额密钥那一套；花费在看板上怎么归。

定图时已定：不推送到手机，主动消息只在用户打开网站时看到；用户正开着网站时到点的主动消息也要能出现。
