# 09: 她说什么：记忆、上次往来和撒娇的分寸

**What to build:** 让她的搭话有内容：接着最近聊过的事说，追问记忆里他的近况，知道上次往来隔了多久；亲近、亲密时照人设撒一点娇。她不提他对别的偶像说过的事，也不发照片。普通文字回合里，她同样知道上次往来是什么时候，撒娇的分寸和搭话一样。规格见 `../spec.md`：「生成一次搭话」里讲每回合变的那条消息和记忆的部分，「回合里的搭话」里讲「上次往来」那一行和撒娇分寸的部分。

**Blocked by:** 08

**Status:** done

- [x] **记忆**：
  - 搭话查记忆时，用最后一个回合（他说的话加她回复的字幕）去查，门槛照旧，最多 3 条。
  - 另外加上最近两周记下、没被取代的近况，最多 5 条（代码常量），和上面查到的去重。
  - 这两样都只取来源是她自己的记忆，写成和回合里一样的记忆那一节。
  - 普通回合的记忆照旧，不加来源过滤。
- [x] **「上次往来」一行**：在「此刻」那一节里加一行「上次往来是 X（隔了多久）」。X 是这一次之前最后一个回合或接通的通话；从没往来过就不写。搭话和每个文字回合都加，通话里的回合不加。
- [x] **撒娇的分寸**：在亲近、亲密两档的语气后面各加几句，写进每回合变的那条消息，回复和搭话共用。
  - 亲近：偶尔轻轻带一句。亲密：可以明着撒娇。信任不加。
  - 怎么说照人设，不 OOC。上一次搭话或回复里抱怨过，这次就不说。
  - 可以说想他、等他、嗔他好久不来；不说难过到哭，不要他保证常来，不要挟。
- [x] **生日**：搭话碰巧落在生日当天时，照现有规矩祝一次；生日本身不另外触发搭话。
- [x] **照片**：搭话里写了照片标签的，把标签丢掉、不生成照片，其余照常记下。

  - 搭话和文字回合的请求里都有「上次往来」一行，内容正确；通话里的回合没有；从没往来过时不写。先例：`test_dynamic_context.py`。

## Comments

### 票 08 交接

- 搭话的请求在 `ConversationEngine.reach_out`：「此刻」一节是 `now_prompt(..., "apart", affinity_prompt(tier, None))`，规矩是 `engine.REACH_OUT_RULES`，放在 `_prompt` 的 `closing` 里（检索结果在文字回合里也放这儿），记忆那一节照这个位置加进 `closing`。
- 照片标签已经丢掉了：`reach_out` 只把文字喂给 `ReplyParser`，`PhotoTagged` 不处理，也没有生图调用；只写了照片标签、没有话的算失败（`test_one_she_could_say_nothing_in_fails_is_not_recorded_nor_tried_again`）。还差一个「写了标签又有话」时记下的测试。

### 实现说明（票 09）

- **搭话的记忆**：`Memories.for_reaching_out(conversation, timezone, last_turn)`（`memory.py`）。查询是 `last_turn_query(messages)`：最后一个回合他说的话，换行，她回复的字幕。只在她自己来源、没被取代的记忆里找（`_nearest` 多了 `character_id`，过滤抽成 `_holding`），重排和门槛照回合（拆出 `_relevant`），最多 `MAX_FOUND` 3 条；再加 `LATELY`（14 天）内记下的最新 `MAX_LATEST` 5 条，按 id 去重，查到的在前、近况新的在前。嵌入失败时只带近况；记忆关着（没有嵌入或重排）时这一节整个不带。`engine.reach_out` 把这一节放在 `closing` 里、搭话规矩前面。
- **「上次往来」一行**：`Store.last_contact(user_id, character_id)`，`now_prompt` 多一个参数 `last_contact`，写成「上次和制作人说话是 M月D日 HH:MM，隔了 N 天。」（不同年时带年份；不到一小时按分钟、不到两天按小时、再往上按天）。文字回合在读完记录时取，通话里的回合不取；搭话也取。通话结束时刻抽成 `store._call_ended`，和 `current_conversations` 共用。
- **撒娇的分寸**：`affinity._FONDNESS`（亲近、亲密各一句）加 `_SWEET_WITHIN_BOUNDS`，接在档位语气后面，回复和搭话共用（通话里的回合也有）。
- **生日**：搭话（`apart`）时换成 `_BIRTHDAY_APART`「今天还没祝福过的话，用你自己的方式祝福一次」，文字回合和通话的那句不变。
- **照片**：票 08 已经丢掉标签，这次补了「写了标签又有话」时记下文字、没有生图请求的测试。
- 测试：`test_reach_outs.py`（记忆、上次往来、生日、照片）、`test_dynamic_context.py`（文字回合的上次往来，通话里没有）、`test_affinity_prompt.py`（撒娇几句并进了分档测试）。`LAST_TALKED` 放在 `test_affinity_prompt.py`，避免测试模块循环导入。

判断题（只报告，没改）：

- 「上次往来」跨这位用户和她的所有对话算，排程用的 `current_conversations` 只看当前对话。搭话只在当前对话里有回合时才来，两者在搭话里取到的是同一个时刻；文字回合里新开的对话第一句也能知道上次说话是哪天。要统一成只看当前对话的话，告诉我。
- GLOSSARY「搭话」说「她搭了话也算一次往来」，那句讲的是对话列表的排序。规格里「最后一次往来」和「上次往来」一行都只算回合和接通的通话，`Store.last_contact` 照规格不算搭话。
- 记忆那一节的标题和每条的写法和回合里一样，开头那句说明换了（`_REACHING_OUT`）：回合里那句是「和这句话可能有关的事」，搭话里没有「这句话」。
- 撒娇两句里加了「隔得久了」才嗔怪好久没来，免得刚聊过一小时她也说「好久没来」。
