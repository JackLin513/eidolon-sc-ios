# 05: 拍板：她说什么

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

主动消息的内容从哪来、怎么写才不假不烦：

- 由头：想到你了、早安晚安、很久没联系、接着上次聊的或记忆里的事追问、制作人生日、她自己那边发生的事（工作、组合的同伴）。由头由代码选好交给模型，还是让模型自己挑？
- 上下文：人设、角色资料、记忆、最近几个回合、好感度档位、现在的时间和制作人那边是几点。她自己那边发生的事从哪来，会不会和原作冲突。
- 长度和语气：和普通回复一样一两句，还是更短。
- 不重复：怎么避免天天说一样的话（拿最近几条主动消息进 prompt？）。
- 用户不回时，下一条要不要接着上一条（「怎么不回我」）还是另起话头；会不会显得在催。
- 安全：主动消息里不能有什么（和回合的规矩一样，还是更严，例如不提用户没说过的私事）。

参考「调研：陪伴类产品的主动消息怎么做」。

## Comments

- 「拍板：主动消息是什么」已定：一次搭话的长度和回复一样，可以分几段，每段日语加字幕；她知道历史范围里每次搭话和说的时间。她挂断过电话之后也可能搭话，提不提、语气怎样在这里定。
- 「拍板：什么时候生成、用谁的模型、谁付钱」已定：搭话由部署者的对话模型生成，用文字回合那一组设定和思考强度；自带 LLM 的用户也一样，所以他的搭话和回复可能出自不同的模型，prompt 写法要不依赖某一家模型。生成时用户多半不在线，浏览器里的东西（设备时区等）都拿不到。
- 「拍板：发不发、发几条」已定：她搭过话就等用户回，所以不存在「连着几条没回」，「怎么不回我」那一问可以去掉；但用户看过不回、下次回了以后，她下一次搭话时历史里会有上次没被回的搭话。搭话只在最后一次往来后 3 小时到 7 天之间发生（亲密最早、信任最晚），时间都在制作人时区的 08:00–22:00，早上 08:00–10:00 最常见；只有信任、亲近、亲密三档会搭话。

## Answer

她自己挑由头，先接着聊过的事；可以有一点撒娇，但不 OOC（2026-10-19 的 grilling）。词汇表「搭话」补了一句：搭话只想起她自己听来的记忆。撒娇的分寸改几句 prompt 就能反悔，不写 ADR。

1. **由头**：她自己挑，不由代码选好。prompt 里先挑接着最近聊过的事、记忆里他的近况，其次才是时间、生日；不许只发一句空问候（「早安」「想你了」后面没有内容）。
2. **她知道的情况**：人设、世界设定、制作人档案、历史照常；另外告诉她：
   - 现在几点（按制作人档案的时区，沿用每回合的日期时间那一行）。
   - 上次往来是什么时候、隔了多久。
   - 最后一个回合之后的对话事件（她挂断了电话、他送了礼物还没被回应）。送了礼没再说话的，搭话就拿礼物当由头道谢，之后那个回合不再要她回应这份礼物。
   - 生日那句照现有规矩（当天只说一次）；生日不另外触发搭话，碰巧在生日当天搭话时才说。
   - 好感度只带档位的语气那几行；判断出的心情、警告和告别那几行不带（没有这一回合的判断）。
3. **记忆**：查询用最后一个回合（他说的和她回的），门槛照旧、最多 3 条；再加最近两周记下、没被取代的几条近况，好让她追问。只用来源是她自己的记忆：别的偶像那里听来的事不拿来搭话（免得像她们在背后议论他）。回复照旧。
4. **不检索、不调工具**：不检索剧情和角色资料，不走判断模型和工具那一轮。她那边的事只说泛泛的日常（练习、拍摄、在事务所）和世界设定里带日期的 live、新歌，不编具体剧情或别人做了什么（和人设里「不编原作」一个规矩）；不加日程数据。
5. **长度和语气**：一两段，不写讲故事那种四段；语气照档位；让他好接话，但不规定每次都用问句结尾。
6. **不重复**：靠历史截取里已有的搭话，加一条规矩「别和前几次搭话用一样的开头和由头」；不另外捞更早的搭话。
7. **撒娇抱怨**：可以有一点（用户觉得「她居然会说这种话」是惊喜，不按「制造依赖」去掉）。
   - 信任不说；亲近偶尔轻轻带一句；亲密可以明着撒娇。档位只管说不说，怎么说照人设，不能 OOC（嘴硬的角色不写成直白撒娇）。
   - prompt 里写「偶尔」；上一次搭话或回复里已经抱怨过，这次就不说。
   - 可以说想他、等他、嗔他好久不来；不说自己难过到哭，不要他保证以后常来，不拿「那我不理你了」这类话要挟。
   - 回复也照这些规矩。所以普通回合的每回合说明里也加「上次往来是什么时候」一行（和第 2 条给搭话的同一行），这是对现有文字回合的改动。
8. **不给跳过的出口**：到点就说，不让模型选「这会儿没什么好说」；发不发只由「拍板：发不发、发几条」的规则决定，内容空洞靠第 1、6 条管。
9. **安全**：人设和世界设定的硬性规则照旧，加上第 3 条（只用自己的记忆）和第 7 条的上限；搭话里不发照片，也不说要给他发照片或打电话。
