# 02: 拍板：主动消息是什么

Type: grilling
Status: resolved
Blocked by: none

## Question

她没被问到就先说的话，在领域里是什么，和现有概念怎么摆：

- 它是一种没有用户那一段的回合，还是一种新的记录（和对话事件并列）？给它定一个正式的名字，写进 `GLOSSARY.md`（暂叫「主动消息」，词汇表里回合要回避「消息」这个词）。
- 一条主动消息只有她的一段话，还是可以是连着的几条？
- 用户回它时，这句话加她的回复算不算一个普通回合；她回复时知不知道自己刚才主动说了什么（当然要知道，但要定它进不进历史截取）。
- 她会不会因为主动消息记下记忆；它过不过判断模型、会不会改变好感度（判断看的是用户的话，主动消息里没有用户的话）。
- 计不计限额、留不留运行记录；对话标题第 3 个回合的计数、统计的回合数、对话列表的最后一句里怎么算。
- 它只进当前对话吗？当前对话已结束、或这位角色还从没聊过时怎么办？历史对话里怎么显示。

定图时查到：代码处处假设回合从用户那一段开始（回合号、历史截取、对话事件的排序、列表最后一句、统计），见 map 的「定图时查到的现状」。

## Answer

正式名字叫**搭话 (Reach-out)**，写进了 `GLOSSARY.md`（「搭话」「没看过的搭话」两条，另外改了「当前对话」「对话事件」「运行记录」）；为什么不当成回合见 `docs/adr/0026-reach-outs-are-not-turns.md`。

1. 搭话是和回合、对话事件并列的第三种记录，「回合」的定义不动。
2. 一次搭话就是一段话，长度和回复一样，可以分几段，每段日语加字幕；隔一阵又说的是另一次搭话。
3. 只在当前对话里搭话。当前对话已结束、她在冷却中、当前对话里还没有回合时，她不搭话，也不为搭话开新对话。挂断电话不妨碍之后搭话。历史对话里的搭话照原样显示。
4. 不经过判断模型，不改变好感度，单独一次搭话不提炼记忆。用户回的那个回合照常判断、照常提炼记忆，判断模型和记忆提炼看到的上文里要有这次搭话。
5. 不计入限额，不算进对话标题的回合数、统计的回合数和「来过」。每次搭话留一条运行记录（新的一种，和回合、通话并列）。搭话算往来，对话列表最后一句显示它。随对话导出、导入、删除，管理者看不到内容。
6. 她知道历史范围里每一次搭话和说的时间。截取照旧按回合数，搭话跟着它后面那个回合走；最后一个回合之后还没回的搭话一律带上。放进历史的写法留给规格，但要所有 LLM 服务都接受（有的不接受连着两句都是她的、或以她开头的历史）。
7. 用户正在和她进行回合或通话时她不搭话；生成完时碰上用户开口，这次作废、不记下。
8. 新增「没看过的搭话」：用户还没打开过所在对话的搭话。在任何设备上打开那个对话就算看过；记在服务器上（离线判断发不发要用）。导入的数据包带来的搭话算看过。怎么显示留给「原型：用户怎么看到」。
