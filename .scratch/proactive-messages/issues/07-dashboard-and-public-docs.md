# 07: 拍板：看板和对外文档

Type: grilling
Status: resolved
Blocked by: 06

## Question

搭话上线前剩下的两处外围：

- **看板**：花费已经自动算进对话模型那一行（「拍板：什么时候生成、用谁的模型、谁付钱」）。看板上要不要单独一节看搭话：每天搭了几次、失败几次、有多少被回了；放在哪个分组标签里，还是只在运行记录里能查。后台设置只有总开关和每天上限两项，已在「拍板：发不发、发几条」定了。
- **对外文档**：隐私政策（服务器在用户不在时用部署者的模型读对话和记忆生成搭话、开关存在服务器上）、使用条款、README 的功能列表要不要改；上线时要不要发一条公告、大意说什么。

## Comments

- 「原型：用户怎么看到」已定：用户的开关在设置里单独一类「搭话」，部署者没开总开关时这一类不出现；搭话在列表和导航上用小圆点标出，网站开着时每 60 秒拉一次列表。

## Answer

看板加一小节，隐私政策和 README 只补几句，条款不动，公告到时候再写（2026-10-19 的 grilling）。没有新词，也不写 ADR。

1. **看板**：「用量」标签里加一小节「搭话」，只有三个数：范围内搭了几次、失败几次、被回的占比。「被回」指这次搭话之后、下一次搭话之前，用户在这段对话里回了一个回合或接通了一次通话。后台总开关没开过、范围内也没有搭话时，这一节不显示。不按角色拆，不进用户页，不单开标签。数都从运行记录里算。
2. **隐私政策**：照照片那次的改法，只补句子，不加版本号，用户不用重新同意。
   - 「语言模型服务」：开着搭话时，你不在线，服务器也会用部署者的对话模型读这段对话和她的记忆，生成她先说的话；填了自己的 LLM 也一样。
   - 「对话」：她搭的话存在对话里，和别的内容一样随对话删除、进备份、随数据包导出。
   - 服务器上存的东西：你的「搭话」开关，以及你看过哪些搭话。
   - 「运行记录」：每次搭话也留一条记录，不含内容。
   - 改「最后更新」的日期。
3. **使用条款**：不改，日期也不动。
4. **README 和配置指南**：三份 README 都在「和她说话」那组加一行，链到配置指南；「🛠️ 后台」那条不改。`docs/configuration.md` 加一节「搭话」：总开关默认关，每位用户每天上限默认 3 次，用部署者的对话模型、花费由部署者出（包括自带 LLM 的用户）。
5. **文案怎么写**：隐私政策和 README 的中文写完先用 humanizer-zh 过一遍，再照「界面文案要少」删减；每处只补一两句，README 那条一行写完，不要 AI 味。英文、日文照中文定稿翻。实现时再定稿，规格里不预先写好。
6. **上线公告**：规格和票里都不写大意。部署者在线上打开总开关时，起草全文给用户确认再发。
