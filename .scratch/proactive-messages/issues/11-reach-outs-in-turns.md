# 11: 回合里的搭话

**What to build:** 用户回了她的搭话以后，她的回复要接着自己刚才说的话，知道自己什么时候搭过什么话。他送的礼物她在搭话里谢过了，回复里就不再谢一遍。判断模型和记忆提炼也要知道他是在回她的搭话，「好啊」这样的短回复不会被误读。规格见 `../spec.md`「回合里的搭话」，依据是 ADR-0026 的 Consequences。

**Blocked by:** 08

**Status:** done

- [x] **历史里的写法**：
  - 搭话写成一句旁白「（M月D日 HH:MM，你先给制作人发了：）」，后面接她的话，写法和历史里她的回复一样。时间按制作人的时区。
  - 这句旁白和对话事件一起，按时间排在它之后那个用户那一段的前面。
  - 截取照旧按回合数切，搭话跟着它后面那个回合走。
  - 最后一个回合之后还没被回的那次搭话，放进这一回合用户那句话前面的旁白里。
  - 历史里的角色顺序不变：不会连着两条都是她的话，也不会以她开头。
- [x] **礼物**：搭话算她已经回应过之前的礼物，之后那个回合不再要她回应。
- [x] **判断模型**看到的上文里，她最近说的那句就是这次搭话，作为她的话放在用户这句前面。
- [x] **记忆提炼**处理这一回合时，带上前面那次搭话，作为她先说的话。
- [x] **记忆查询**里「她上一句」用这次搭话的字幕。
- [x] 通话里的回合也一样：通话接通前的那次搭话也在历史里。
- [x] **测试**（后端）：
  - 历史：旁白的位置和写法对；截取以后搭话跟着后面的回合走，它前面的回合被截掉时它还在；还没回的那次出现在这一回合的旁白里；各协议发出去的请求里，角色顺序都合法。先例：`test_conversation_history.py`、`test_dynamic_context.py`、`test_llm_protocols.py`。
  - 礼物：送礼后她搭话，再来一个回合，请求里不再有「回应礼物」那句。先例：`test_gift_responses.py`。
  - 判断和记忆：判断模型和记忆提炼收到的内容里有这次搭话；记忆查询用的是搭话的字幕。先例：`test_affinity_turns.py`、`test_memories.py`。
  - 缓存：加了旁白以后，下一回合请求的开头仍和上一回合一致，前缀缓存不被破坏。先例：`test_dynamic_context.py`。
- [ ] `sh scripts/affected-tests.sh <基点>` 通过，推送后 CI 全绿。

## Comments

### 票 08 交接

- 文字回合现在读记录时用 `engine._without_reach_outs` 把搭话滤掉（`_reply` 和 `reach_out` 都是），`narrations` 的参数类型也只收消息和对话事件；这张票把搭话接进历史时从这里改。
- `titles` 起标题前也滤掉了搭话（规格说起标题不带搭话），这一条保持。
- 搭话旁白的「最后一个回合之后的对话事件」在 `engine._events_since_last_turn`。

### 实现说明（票 11）

- `engine.py`：回合和搭话都不再滤掉搭话。`narrations(record, gift_catalog, timezone)` 把事件和搭话一起讲（`_narration_line`），搭话那行是「（M月D日 HH:MM，你先给制作人发了：）」加 `format_reply(segments)`，带着原样的提示标记；遇到搭话就清掉「还没回应的礼物」。`_events_since_last_turn` 改名 `_since_last_turn`，也讲搭话。
- 判断模型、检索（记忆查询）、记忆提炼共用的 `history` 末尾接上最后一个回合之后的搭话（`_answering`，用新加的 `ReachOut.as_reply()` 当成她的回复；id 是搭话表的，下游不按 id 用历史）。
- 测试在 `tests/test_reach_outs_in_turns.py`：旁白位置和写法、截取、事件和搭话按时间排加礼物、前缀缓存、三种协议的角色顺序、判断/查询/提炼的上文、通话。
- 判断题（没改）：旁白的时间用当回合的时区（`effective_timezone(profile, device_timezone)`，和「此刻」一节一致）。档案没填时区、又在不同时区的设备之间换着用的用户，旧旁白的时间会跟着变，那一回合前缀缓存失效；改档案时区也会重写所有旧旁白。改成只用档案时区则稳定，但和「此刻」对不上。
- 判断题（没改）：最后一个回合之后有不止一次没回的搭话（只有接通过一次没说话的通话时才会有）时，旁白和上文都按时间全带上，没有单独测。
