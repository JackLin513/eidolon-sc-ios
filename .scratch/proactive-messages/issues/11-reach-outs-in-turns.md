# 11: 回合里的搭话

**What to build:** 用户回了她的搭话以后，她的回复要接着自己刚才说的话，知道自己什么时候搭过什么话。他送的礼物她在搭话里谢过了，回复里就不再谢一遍。判断模型和记忆提炼也要知道他是在回她的搭话，「好啊」这样的短回复不会被误读。规格见 `../spec.md`「回合里的搭话」，依据是 ADR-0026 的 Consequences。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] **历史里的写法**：
  - 搭话写成一句旁白「（M月D日 HH:MM，你先给制作人发了：）」，后面接她的话，写法和历史里她的回复一样。时间按制作人的时区。
  - 这句旁白和对话事件一起，按时间排在它之后那个用户那一段的前面。
  - 截取照旧按回合数切，搭话跟着它后面那个回合走。
  - 最后一个回合之后还没被回的那次搭话，放进这一回合用户那句话前面的旁白里。
  - 历史里的角色顺序不变：不会连着两条都是她的话，也不会以她开头。
- [ ] **礼物**：搭话算她已经回应过之前的礼物，之后那个回合不再要她回应。
- [ ] **判断模型**看到的上文里，她最近说的那句就是这次搭话，作为她的话放在用户这句前面。
- [ ] **记忆提炼**处理这一回合时，带上前面那次搭话，作为她先说的话。
- [ ] **记忆查询**里「她上一句」用这次搭话的字幕。
- [ ] 通话里的回合也一样：通话接通前的那次搭话也在历史里。
- [ ] **测试**（后端）：
  - 历史：旁白的位置和写法对；截取以后搭话跟着后面的回合走，它前面的回合被截掉时它还在；还没回的那次出现在这一回合的旁白里；各协议发出去的请求里，角色顺序都合法。先例：`test_conversation_history.py`、`test_dynamic_context.py`、`test_llm_protocols.py`。
  - 礼物：送礼后她搭话，再来一个回合，请求里不再有「回应礼物」那句。先例：`test_gift_responses.py`。
  - 判断和记忆：判断模型和记忆提炼收到的内容里有这次搭话；记忆查询用的是搭话的字幕。先例：`test_affinity_turns.py`、`test_memories.py`。
  - 缓存：加了旁白以后，下一回合请求的开头仍和上一回合一致，前缀缓存不被破坏。先例：`test_dynamic_context.py`。
- [ ] `sh scripts/affected-tests.sh <基点>` 通过，推送后 CI 全绿。
