# 08: 拍板：制作人的赞和评论、她在对话里怎么知道朋友圈

Type: grilling
Status: open
Blocked by: none

## Question

已定：制作人能赞、能评论，她用对话模型回一次，过一阵才露出来；评论不经过判断、不改好感度、不变成记忆、不算往来，计入每天的评论回复上限；她在对话里知道最近发了什么、制作人赞了没有、评论了什么。还要定：

- **赞**：能取消吗？她知道「赞了又取消」吗？
- **评论**：长度上限；一条动态制作人能评论几次（第二条她还回吗，还是只回第一条）；能删自己的评论吗，删了她的回复怎么办；她在冷却中、好感度冷淡时还回不回。
- **她的回复**：多久之后露出来（固定区间、随好感度变）；回复时她看得到什么（这条动态、其他偶像的评论、制作人这条评论、她最近的对话？）；回复上限用完了怎么办（不回，还是她「已读不回」也算一种表现）。
- **此刻里带什么**：最近几天的动态（几天、几条），赞和评论怎么写进去；打字、通话、搭话、光顾时各带不带。
- **对话里提到朋友圈**：她会主动提（比如搭话时「你看到我昨天发的了吗」），还是只在被问时提；制作人没赞没评论时她会不会在意，好感度不同表现是否不同。
- 自带 LLM 的用户：评论回复仍由部署者的对话模型写，和搭话一致——确认没有例外。
