# 07: 拍板：发布节奏和调度

Type: grilling
Status: open
Blocked by: none

## Question

已定后台定时生成、只给最近活跃的用户、每位角色每天最多 1 条、每位用户每天合计最多 N 条（默认 3）。还要定：

- **最近活跃**怎么算：7 天内有过回合？通话、送礼、打开朋友圈算不算？
- **一天里谁发**：合计上限 N 比「有过回合的角色」少得多时，每天挑哪几位——好感度高的优先、今天做完了工作的优先、生日的必发、轮流避免总是同一位？好感度档位具体怎么影响频率（照搭话的 `INTERVALS` 那样按档位给间隔，还是给权重）。
- **几点发**：按东京时间在一天里怎么分布（早上、午休、下班后、深夜），做完工作的那条在工作最后一个时间段之后发。制作人的时区要不要考虑（他夜里收到也不提示）。
- **提前生成还是到点生成**：到点才生成文字和配图，还是提前一批生成好、到点露出来（生图排队，部署者 key 默认同时只生成 1 张）。
- **和搭话、照片抢生图队列和对话模型**：动态的生图排在用户要的照片后面吗？
- **开关和条件变化**：部署者没配生图时只发纯文字；部署者没配对话模型或关掉朋友圈时不发；用户关掉自己的朋友圈、好感度掉到疏远、进入冷却时，已经生成好还没露出来的动态怎么办。
- 部署者在后台能调的数：N、每天评论回复上限、活跃天数，哪些要暴露，默认值。
