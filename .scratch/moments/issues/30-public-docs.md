# 30: 隐私政策、使用条款、README、配置指南、术语表

**What to build:** 用户在隐私政策里读得到：朋友圈存了什么、谁看得到、什么时候删、交给了哪些服务；使用条款写明朋友圈里的动态和评论也是 AI 扮演的，赞和评论不影响好感度。部署者在 README 和配置指南里看得到朋友圈怎么开、能调什么、谁出钱。规格见 `../spec.md`「隐私政策、使用条款、对外文档」，来历是 `12-privacy-and-terms.md`。

**Blocked by:** 18, 19, 25, 26, 27, 28

**Status:** ready-for-agent

- [ ] **改法照旧例**：
  - 隐私政策、使用条款都只补句子、改「最后更新」的日期。
  - 不加版本号，用户不用重新同意，同意页不动。
  - 功能关着时也照写，用「开着朋友圈时」这类条件句。
  - 中文先写，用 humanizer-zh 过一遍再删减。文案在前端 i18n 的 `privacy`、`terms` 两段，只有中文。
- [ ] **隐私政策**，要点照规格写：
  - 「我们保存哪些数据」：在「搭话」前面加一条「朋友圈」。不写「删除记忆不改变已发的动态」。「对话」「登录状态和限额的计数」两条不动。
  - 「运行记录」：加上每条动态和她每次回你的评论；「角色发照片时」改成「角色发照片或配图时」。
  - 「语言模型服务」「生图服务」各补一句。「向量化和重排服务」不改。Open-Meteo 和地图链接都不写。
  - 「管理者能看到什么」：「看不到」里加上你的朋友圈，再补半句「只能看到所有用户合起来的统计」。「能看到」不改。
- [ ] **使用条款**：
  - 「角色由 AI 扮演」：「和你说话的角色」改成「和你说话、在朋友圈发动态和评论的角色」。
  - 「玩法」加一句：你在朋友圈的赞和评论不影响好感度。
- [ ] **README**（三种语言）：功能那一组加一行「朋友圈」，链到配置指南。「致谢」里的 OSM、Open-Meteo 已经由 15、18 加上，这里核对一遍。
- [ ] **配置指南**（三种语言）：
  - 开关一览表加一行 `EIDOLON_MOMENTS=1`（默认关）。
  - 加一节「朋友圈」，写清：
    - 总开关默认关；
    - 每位用户每天的动态默认 3 条，回评论上限默认 10 条；
    - 地图链接可以换成高德或 Google，大陆不开代理打不开 OpenStreetMap；
    - 用部署者的对话模型和生图，花费由部署者出，自带密钥的用户也一样；
    - 天气来自 Open-Meteo，不要 key。
  - 看板那一行补上朋友圈。
  - 英文、日文照中文定稿翻译。
- [ ] **术语表**：「运行记录」补上每条动态和她每次回评论也各留一条记录；「此刻」补上此刻里有她最近发的朋友圈。都只补半句，不改别的条目。
