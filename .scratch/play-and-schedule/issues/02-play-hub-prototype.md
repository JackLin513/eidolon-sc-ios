# 02: 原型：玩法页长什么样

Type: prototype
Status: resolved
Blocked by: none

## Question

导航中间的「礼物」改成「玩法」，礼物、每日任务、成就收进这一页，一样一栏，以后日历和小游戏也往里加。现在的礼物页是一整页往下排（推荐、抽奖台、每日任务、成就、重置卡、背包），见地图「定图时查到的现状」。要定：

- 玩法页本身是什么样：一栏一栏的入口卡片，还是直接摊开内容；每栏显示什么（标题、图、一句状态，比如「还有 3 次抽奖」「今天完成 2/3」）。
- 栏怎么分：「礼物」一栏（抽奖台、重置卡、背包、推荐）和「每日任务与成就」一栏，还是三栏；点进去是现在的礼物页原样，还是拆成几个子页。
- 子页的路由和返回方式；手机上从导航进来、从子页回来的感觉；桌面侧栏是不是也同样改成「玩法」。
- 导航「玩法」上的点：现在「礼物」上的点（新的抽奖次数）怎么搬过来，玩法页里在哪一栏上标。
- 「日历」一栏的位置先占好（内容由日历原型票定）。
- 关掉好感度和礼物的部署、访客看到的玩法页是什么样（礼物、任务、成就都不出现时，是空页还是只剩日历）。

做法：在 `prototype/play-hub` 分支上做可以点的前端原型，手机和桌面各看一遍，给用户比两三种方案。

## Answer

用户选了变体 A「入口卡片 + 子页」（2026-10-23）。原型在 `prototype/play-hub` 分支（c2f6fe7）：`/gifts?variant=A|B|C|D`，`?col=` 选栏目，`?closed=1` 模拟没开放。另外三种（B 两级列表同设置、C 标签直接摊开、D 现在的一整页加日历条）没选。

- **玩法页本身**：一张张入口卡片，不直接摊开内容。每张卡片上有圆底图标、名字（Header 字号）、右端 ›，下面一句 muted 的状态。「礼物」卡铺 `bg-muted`、占满一行放在最上面；下面「每日任务与成就」「日历」两张描边卡并排，窄屏时一列。内容最宽 `max-w-3xl`，手机和电脑同一个版式，不用设置那样的两栏。
- **栏怎么分**：两栏，加上日历。
  - 「礼物」：抽奖台、重置卡条、我的礼物，以及从对话页跳来时预选的那一条。状态写「还有 n 次抽奖 · 背包 m 件」，有重置卡时加「· 重置卡 k 张」。
  - 「每日任务与成就」：现在的两节放在同一页。状态写「每日任务 今天 2/3」（都做完了就写「今天都做完了」），有新解锁的成就时加「· 成就 n 个新解锁」。
  - 「日历」：先占好位置，状态和内容由「原型：日历和排日程的界面」定。
  - 以后加的玩法同样一栏一张卡。
- **子页和返回**：点卡片进这一栏的子页，页首是 `SubpageHeader`，返回键回玩法页。手机和电脑都有返回键，因为两种宽度下子页都占满整块，不和列表并排。在子页上再点导航「玩法」也回到玩法页，规则同对话、设置的第二级。桌面侧栏和手机 dock 都改叫「玩法」，图标换成 lucide `Shapes`。
- **跳转**：
  - 对话页的「送她一件礼物」（冷却行、结束卡、好感度 Popover）直接进「礼物」子页，带着预选的她。
  - 每日任务里的「挑一件」跳到「礼物」子页，原来是在同一页上滚到「我的礼物」。
  - 「去对话」照旧。
- **点**：导航「玩法」上的点还是原来那个（新到的抽奖次数），写法、读屏都照旧，只把名字改成「玩法」。在玩法页的任何一级上，导航都不出点。玩法页里，新到的抽奖次数标在「礼物」卡名字旁，进了「礼物」子页才记成看过；新解锁的成就标在「每日任务与成就」卡上，离开那个子页才记成看过（同现在离开礼物页的规则）。
- **没开放时**：好感度和礼物关着时，「礼物」「每日任务与成就」两张卡都不出现，只剩「日历」一张卡。原型里这样看过，用户没有提出不同意见。导航「玩法」照样在。
- **路由**：原型没有专门定。规格照设置的写法：第一级 `/play`，子页 `/play/gifts`、`/play/tasks`、`/play/calendar`；旧的 `/gifts`（连同 `?to=`）跳到 `/play/gifts`。具体名字在规格里再核对一次。
