# 05: 拍板：排日程的规则

Type: grilling
Status: resolved
Blocked by: 04

## Question

制作人把本周的工作排进日程。已定：一天上午、下午、晚上三段，按制作人的时区算；时间段开始后不能再改或撤；排的时候要提醒、二次确认；没排的到下周一作废。要定：

- 票 04 已定：整周一个时间段只排一项工作，不分哪位偶像；工作占 1 到 3 段、不跨天，有的限制时段；每周发布的总时长多于 21 段，排不下全部。要定：一项工作排了以后还能不能挪（时间段开始之前）；多段的工作开始以后，后面的段是不是一起锁住。
- 二次确认在什么时候弹：每排一项都确认，还是排完点「确定本周日程」一次确认；确认后在开始之前还能不能改。
- 周中第一次来的用户：已经过去的时段不能排，剩下的照常；周日晚上才来的用户几乎排不了，这样行不行。
- 制作人改了档案里的时区：已经排的日程怎么算（按新时区重新解释，还是锁住原来的时刻）。
- 北京时间周一 0 点换新和制作人时区的周一不一致时（比如在美国），换新那一刻她的「本周」怎么接。
- 排日程要不要受好感度影响（冷淡、冷却中的偶像能不能排）。

每张票都调用 grilling 和 domain-modeling。

## Answer

2026-10-23 的 grilling 定下：

- **时间段**：上午 6–12 点、下午 12–18 点、晚上 18–24 点，按制作人的时区；0–6 点不属于任何时间段。
- **本周**：按制作人时区的周一到周日算。工作在北京时间周一 0 点发布，发布后就能排，所以北京以西的制作人能提前排下一周；没排的工作在他自己那一周的格子都过去后作废。
- **草稿与保存**：先在草稿里摆，她看不到；草稿只存在本机（刷新、换页不丢，换设备看不到，过了那一周清掉）。点「保存」时弹一次确认，列出这次新加的几项（哪天哪段、谁、做什么），写明保存后不能更改。
- **保存即锁住**：保存过的工作开始前也不能挪、不能撤（收紧了定图时「开始以后不能改」的说法）。空格之后还能补，每次保存都再确认一次。
- **保存时已开始的格子**：这几项退回待排区、提示一句，其余照常保存；在确认前还是确认后剔掉由票 07 定。
- **能排的格子**：已过去的和正在进行的格子不能排；周中才来的只能排剩下的，不补偿。
- **改时区**：日程按「周几、哪一段」存，改时区后按新时区重新解释。
- **好感度**：不影响排日程，冷淡、冷却中的偶像也能排。
- **词汇表**：「日程」补上保存后不能改、本周按制作人的时区；新增「时间段」。
