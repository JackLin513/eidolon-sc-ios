# 07: 拍板：上了酒之后怎么判、戏怎么走、好感度加多少

Type: grilling
Status: resolved
Blocked by: 01, 02, 05

## Question

制作人上了一杯饮品，服务器怎么判、她怎么反应。要定：

- **判定的档位**：上对、上得更好、上错（差得不多 / 完全不对 / 调失败了的饮品），各自她的反应和后面的戏怎么变（照票 02 原版的做法）。上错了她会不会再给一次机会。
- **酒精**：Karmotrine 的量（含大杯）怎么累积成「醉」，醉了几档、各自什么样（定图时的护栏：只是话多、犯困、情绪起伏、说心里话）；故意把她灌醉算上对还是上错，原版有没有「灌醉才能听到的话」那种隐藏分支，我们要不要。
- **好感度加多少**：定图时定了上对多加、上错少加、都不降，只有当天第一次玩完的光顾算。按「好感度放慢」那把尺子（`.scratch/play-and-schedule/issues/11-*`）和礼物、工作比，这次光顾整体加多少，按杯算还是按整次算。
- **抽奖次数**：当天第一次玩完给几次，算不算进每天发的上限（成就给的不算上限，酒吧的呢）。
- **什么算「玩完」**：最后一杯上完、她离开那一刻；中途走了不算。
- **选项**：偶尔出现的两三个选项（制作人的台词）放在哪里、选了怎么影响戏，影不影响好感度。
- 调错的饮品：原版对不上配方的是「故障瓶」，上不了、只能重做（票 01）；照搬，还是允许上、算上错。
- 原版吧台上**没有选项**、上错几乎不让重做、只有「连着乱上最省事的」会被赶回家（票 02）。定图时定的「偶尔给两三个选项」要不要留，也在这里定。

## Comments

### 票 04 交接

- 每位角色有讨厌的口味（0–1 种）：上了讨厌口味的饮品，反应换成不喜欢，好感度照「上错升得少、不降」。这一档加多少在这里定。
- 每位角色有酒量（弱、中、强），只是三档；Karmotrine 累计到多少算醉，按这三档各定门槛。

### 票 05 交接

- 每单的判定已经收成三样：算对的范围、范围里「上得最好」的几款（直说名和打比方的单没有这一档，范围里没她爱喝的也没有）、范围外。这里给各档起名、定反应和好感度。
- 她讨厌的口味在任何说法下都算上错，说了无酒精却上了含酒的也算上错；这两种错法要不要比普通上错更重（专门的不喜欢反应），在这里定。
- Flaming Moai 不收，照它的配方调出来是故障瓶；故障瓶怎么处理还是这里定。

### 票 06 交接

- 醉了以后的骨架已经定了：当前这杯的反应照常写，从下一段起换成醉的写法；计划好的后面几单不再点，短闲聊后进醉的告别；这次光顾记成「醉了」。这里只要定每档酒量的门槛（按每杯含的酒精份数累计，大杯算翻倍），以及醉了几档。
- 告别要带一句这次喝得怎么样，所以整次光顾的上对、上错情况要交给写告别的那一段。
- 骨架里没有给选项留位置。要留选项的话，在这里定放在哪一段。
- 「老样子」这一单没有「上得最好」这一档（票 05 已补修订）。

## Answer

2026-10-26 拍板。对错只由服务器判，模型照判定结果写反应。

**三档判定**：每杯判成「上得最好」「上对」「上错」之一，范围照票 05。上错时服务器另外告诉模型错在哪：口味对了种类不对（或反过来）、她讨厌的口味、说了不要酒却有酒、完全不对、不是上次那款（老样子）。讨厌的口味和不要酒却有酒这两种，写成明显的不喜欢；好感度和别的上错一样，不加重。

**上错照常往下走**：不让重做，她抱怨或挖苦几句就照常往下聊，下一单照点。原版「连着三次乱上最简单的就被赶回家」不照搬，没有惩罚。

**调坏的饮品**（原版的「故障瓶」）：对不上任何配方的不能上，只能倒掉重调，次数不限；恰好等于另一款配方的就是那一款，可以上，照常判。Flaming Moai 的配方也算调坏。词汇表不收这个词，它是界面上的事。

**醉**：
- 醉意进门时从 0 开始，每上一杯加上这杯的 Karmotrine 份数（大杯按翻倍后的份数）。
- 只分没醉和醉了。门槛按酒量：弱 8、中 14、强 20，写成常量。按这个数，弱的喝两杯 Beer 就醉，中等的要三四杯或者有大杯，强的除非故意灌，很难醉。
- 瓶装的份数：Absinthe 6、Rum 6、A Fedora 3；Mulan Tea 算无酒精（0 份），说了不要酒时上它算满足条件（原版代码标的是含酒，这一条不照搬）。
- 界面不显示醉意。醉了以后怎么走照票 06。
- 故意灌醉不算错：判定只看点单条件，往可选 Karmotrine 的饮品里多加酒，仍然是那一款。醉了不加分也不减分。没有「灌醉才听得到」的隐藏分支或标记，醉的写法里本来就有的说心里话就是这一层。

**好感度**：只看当天第一次玩完的光顾，按整次算，取每杯的平均分：上得最好 0.5，上对 0.4，上错 0.1。没有「上得最好」这一档的单（直说饮品名、打比方、老样子，或者范围里没有她爱喝的），上对就记 0.5。所以一次最多 +0.5，和一项工作一样大。当天第一次来的人是按日期定的，同一位平均 29 天才轮到一次，所以不打乱票 11 的节奏。
- 冷却中的她照样会来：不从池子里拿掉，态度照冷淡这一档写；玩完照上面的数加，跟工作一样，不用冷却里礼物那个固定的 +3。
- 好感度和礼物关着时什么都不给（定图时已定）。

**抽奖**：当天第一次玩完给 1 次，和每天发的一样受上限 7 约束，攒满了就不给。导航「玩法」上的点照旧亮，表示有新到的抽奖次数。

**什么算玩完**：服务器发出告别那一段的那一刻，醉了提早告别也算；在那之前离开都不算。中途离开以后怎么办，留在地图上「中途离开」那块雾里。

**没有选项**：照原版，吧台上不给制作人的台词选项，玩家影响这次光顾只靠上什么酒。定图时定的「偶尔给两三个选项」撤掉，制作人的台词全由模型写。

**不做钱**：价格、小费、提成和结算页都不做。光顾结束时只显示得到了什么：抽奖 +1，好感度上升的方向（不显示数字）。不给评分，也不列上对了几杯，这次喝得怎么样交给她告别时那句话。

**词汇表**：「点单」补上三档的名字，新加「醉」；「光顾」补上什么算玩完，以及冷却中照样会来。
