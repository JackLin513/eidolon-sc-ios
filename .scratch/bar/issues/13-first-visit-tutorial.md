# 13: 拍板：第一次进酒吧的引导

Type: grilling
Status: resolved
Blocked by: 12

## Question

现在没有一处说明酒吧怎么玩，没玩过 VA-11 HALL-A 的人进来不知道该干什么。用户的设想：第一次进酒吧时先不选歌，点一下进门；はづき 像原版的 Gil 那样，点一两杯，借着这几杯介绍拖材料、加大杯、调制（mix / blend）、加冰、陈化等功能，再说明客人点单会有不同的说法和要求；最后介绍点唱机：每次开店前要先选好曲目，然后才能开店。在这个设想上定：

- **它是什么**：算不算一次光顾（进不进光顾记录、给不给抽奖和好感度、占不占「光顾」限额、写不写运行记录）；词汇表里叫什么（「引导」「教学」还是别的），和「光顾」怎么区分。
- **谁来、说什么**：はづき 当「Gil」时是什么身份（照常是 283 的事务员、在这个 IF 里是这家店的前辈或老板？）；台词是写死的还是模型现写（写死就不花钱、不受自带 LLM 影响、可以逐步对上操作；由 agent 起草、用户校对）；ja 加 zh 字幕照 ADR-0001。
- **教什么、按什么顺序**：点几杯、各是哪款、每杯教哪几项；画面上怎么提示（台词、高亮、锁住别的按钮）；调错、上错、调坏了怎么办；点单的八种说法讲到什么程度；配方书、点单备忘、电视、键盘快捷键、离开讲不讲。
- **和流程的接缝**：第一次进来时跳过选曲界面，引导结束时再带去选曲（票 11 定的是每次先过选曲界面）；引导时放不放音乐；中途离开、刷新怎么办（重来还是从中间接着）。
- **记在哪、能不能重看、能不能跳过**：「看过引导」存在账号上还是本机；老用户、换设备的怎么算；跳过的入口和以后重看的入口放在哪（侧边菜单、开店画面）；没有对话模型、或者开关关着时有没有影响。
- **对票 10 的影响**：引导放进哪份规格（大概是「酒吧的店面」），要不要后端；要不要画面原型（如果提示方式拿不准，另开一张原型票）。

## Answer

2026-10-26 和用户逐条定下（grilling，十二问全照建议）。术语表「酒吧」一节加了「教程」。依据是「调研：原版的引导教程怎么教」的笔记，骨架照原版。

**它是什么**
- 叫**教程**，界面上也写「教程」，不说引导、教学。第一次进酒吧时 はづき 教制作人调酒的一段戏。
- 不是光顾：不进光顾记录，不给抽奖和好感度，不占「光顾」限额，不写运行记录（不调模型）。也不算进票 05「新手头 3 次不出最难的说法」，那 3 次从第一次真正的光顾数起。没配对话模型的部署也能走。

**谁来、说什么**
- はづき 照常是 283 的事务员，这个 IF 里在酒吧打过工（人设本来就「还在别处打工」），制作人第一天当酒保，她下班顺路来带一带。不是老板，不交代店是谁的。她照常在光顾的池子里，光顾里的她不记得教程。
- 台词写死在仓库里：はづき 日语一句配中文字幕（ADR-0001），制作人一句中文，每句带情绪驱动立绘。由 agent 起草，作为「酒吧的店面」规格里的一张起草票，做完停下等用户校对。

**教什么、怎么教**
- 照原版两杯，都直接说名字：第一杯 Sugar Rush（拖材料、调制、上酒、重做、配方书），第二杯 Moonblast（调和、加冰）。收尾口头讲大杯、陈化、Karmotrine 和加多了容易醉，不考。
- 保留 Piano Man 彩蛋：第一杯直接调出 Piano Man 就跳过第二课，收尾照讲。
- 收尾多两三句点单：客人不一定说名字，会说口味、种类、几个条件、打比方，或者让你拿主意；左上的备忘会记着；上得不对她会抱怨，但不会让你重做。讨厌的口味、「上得最好」、醉的门槛、电视、键盘快捷键、「离开」都不讲。
- 提示照原版：只靠台词，加侧边菜单上的点单备忘写成这一步的要点。不高亮、不画箭头、不加遮罩，也不额外锁按钮（说话时调酒台本来就锁着）。不开画面原型票。
- 出错照原版：每杯只判一次，调对、调成 Piano Man、调成别的各接一段反应，然后都往下走，教程一定走得完。调坏的上不了，只能重做（票 07）。

**和流程的接缝**
- 第一次进店跳过选曲界面（票 11「每次先过选曲界面」的例外），直接到店门口，点一下进门开始教程。
- 教程期间放固定曲 Every Day is Night（取不到音频就静音），侧边菜单「点唱机」那一格换成「跳过」。
- 收尾 はづき 说一句「这台点唱机要先选好 12 首才放」，弹出选曲界面（填好默认 12 首），Ready! 回到店门口，再点进门就是第一次真正的光顾。取不到音频时省掉这句，直接回店门口。
- 不记进度：中途离开、刷新都从头再来，没走完不算看过。

**记在哪、跳过和重看**
- 「看过教程」只存在这台设备的 localStorage，走完或跳过都算看过。不改后端，不进数据包、隐私政策和删账号流程。换设备、清浏览器数据会再出现一次，跳过就行。功能是新的，老用户不用特殊处理。
- 跳过：教程期间侧边菜单「点唱机」那一格换成「跳过」，点了直接去选曲界面，不弹确认框。
- 重看：店门口那一屏放一个小像素按钮「教程」，和安卓的「全屏」按钮在一起，点了从头走一遍，重看时也能跳过。

**对票 10 的影响**
- 教程整块归「酒吧的店面」，纯前端，不用后端。「光顾」规格不变。
- 「酒吧的店面」多一张起草票：教程台词（はづき 日语加中文、制作人中文、每句情绪，含三种结果的反应和 Piano Man 分支）。
- 「酒吧的店面」合并前的人工验收加一项：走一遍教程（含跳过和重看）。
- 地图里「引导的画面」那块清掉。这张以后地图没有剩下的票，交给 `/to-spec` 写两份规格。

**ADR**：不写。
