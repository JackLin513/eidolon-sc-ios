# 05: 拍板：她怎么点单，什么算上对

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

照原版（票 02 的结论）定酒吧里点单的说法，以及每种说法下什么算上对：

- 采用原版的哪几类说法，各占多少比例；第一次来的人会不会一上来就遇到最含糊的那种（要不要按难度分布）。
- 每类说法下「上对」的范围：只认一款，还是满足条件（口味、种类、温度、大杯、含不含酒精）的都算；有没有「上得更好」这一档（比如说了「随便」，上了她最爱的）。
- 点单的那句话由谁决定：服务器先定好「这一单是什么、接受哪些」，再让模型照着说出来（胜负由服务器判）；模型要保证说出来的话和服务器定的一致，不能透露答案，也不能说偏。
- 玩家怎么找饮品：配方书能按名称、口味、种类查（照票 01 原版的分类），要不要给「再问一次」或者提示。
- 饮品的名字：官方中文版不译饮品名（票 01），我们照用英文原名，还是自己起中文名、或者英文名加中文注；她点单时（日语台词）用什么名字。
- 照搬的范围：瓶装的 4 款（Absinthe、Rum、Mulan Tea、A Fedora）和隐藏的 Flaming Moai 要不要。
- 原版的判定逐单手写（票 02），我们得把它收成几条通用规则：每类说法对应一种「接受范围」，加上「最好的那款」一档。说「老样子」「考考你」这类要她记得上次喝什么的说法，看票 06 定不定酒吧自己的记录。

## Comments

### 票 04 交接

- 票 04 每一单先抽出一款**目标饮品**（爱喝的 45%、合口味的 35%、心血来潮 20%），这张票定她怎么把它说出来、哪些算上对。说口味、说种类的点单，接受范围可以从目标饮品的口味、种类推。
- 每位角色有酒量（弱、中、强）：酒量弱的点「含酒精可选」的饮品时会不会更常要无酒精版，在这里定。
- 她讨厌的口味永远不会是目标饮品；但「随便」「你拿主意」这类说法下制作人上了她讨厌的口味，算不算上对、算哪一档，在这里或票 07 定。
- 瓶装和隐藏款留不留：留下就进抽奖池、也能当爱喝的。
- 「老样子」「来杯我喜欢的」：她的爱喝的饮品就在 `bar_favorites`，界面不显示，模型拿得到。

## Answer

2026-10-26 拍板。每单先按票 04 抽出目标饮品，再抽一种说法；算对的范围和「最好的那几款」都由服务器从目标饮品推出来，模型只照着说。

**说法和算对的范围**（占比写成常量，上线后再调）：

| 说法 | 占比 | 能出的条件 | 算对 | 上得最好 |
|---|---|---|---|---|
| 直说饮品名 | 45% | 都能出 | 只认这一款 | 没有这一档 |
| 饮品名加大杯 | 7% | 目标有大杯 | 这一款，小杯也算对 | 大杯 |
| 说口味 | 12% | | 这个口味的都算 | 范围里她爱喝的 |
| 说种类（可以绕着说，「烈的」就是 Manly） | 12% | | 这个种类的都算 | 同上 |
| 几个条件叠加（口味或种类，加冰、无酒精、大杯） | 8% | | 条件全满足才算 | 同上 |
| 照描述打比方 | 8% | 目标有配方卡描述或瓶装小字 | 只认这一款 | 没有这一档 |
| 「来杯我喜欢的」 | 4% | 目标从她爱喝的里抽出 | 她爱喝的任一款，或口味、种类合她心意的 | 她爱喝的 |
| 「你拿主意」 | 4% | | 都算 | 她爱喝的 |

- **通用规则**：她讨厌的口味在任何说法下都算上错，宽的说法也一样。她没提到的条件不管（没说无酒精，含不含酒都行；没说大杯，做大杯也算对）。说了无酒精却上了含酒的，算上错。范围里没有她爱喝的，这一单就没有「上得最好」这一档。
- **不收的说法**：说错、言不由衷；要一种效果（「让我喝醉」）；酒保拿主意的剧情点；一次点两杯（一单只点一杯）。「老样子」「考考你上次喝的什么」等票 06 定她记不记得上次的事。
- **难度**：这位用户头 3 次玩完的光顾里，不出「照描述打比方」和「几个条件叠加」；「来杯我喜欢的」要这位用户和这位角色至少玩完过一次光顾才出。门槛写成常量。
- **酒量**：目标是能选含不含酒的那 7 款时，酒量弱的 40% 补一句「不要酒精」，中等的 10%，强的不补。补了就变成带无酒精条件，照硬条件判。
- **谁定、谁说**：服务器给写戏的模型一张点单卡（说法、目标饮品的名字、口味、种类、描述、要提哪些条件、能不能说出名字），对错只由服务器判。模型写完后服务器检查：不该说名字的说法里，日语台词和中文字幕都不能出现任何饮品的英文名或日文名；该说名字的要真说出来。不过就重写一次，再不过就换成写死的模板句。
- **点单备忘**：要做。文字由服务器按点单卡套模板，用制作人的口吻（「她要 Sugar Rush，大杯。」「她要甜的，不要酒精。」）；打比方的那单复述她那句话的中文字幕。不交模型写，所以模型说偏了备忘也是准的。
- **找饮品**：不做「再问一次」，也不做提示。配方书照原版四个标签（名称、口味、种类、瓶装），不加组合筛选。
- **饮品名**：配方书、备忘、中文字幕都用英文原名（跟官方中文版一致），不起中文名；她的日语台词用日文版译名（シュガーラッシュ），字幕里换回英文原名。
- **照搬范围**：一共 28 款。瓶装 4 款留下、一直都在（不照原版让 Absinthe 和 Rum 二选一），进抽奖池、也能当爱喝的；Flaming Moai 不收，照它的配方调出来算故障瓶。数据冲突照票 01 的建议：以配方卡为准（Piano Man 是 Sour），中文标签用菜单分类名（Classic 经典、Classy 时尚）。
- **词汇表**：「点单」补上了说法的几种和「算对的范围」。「上对」「上错」「上得最好」各档的名字留给票 07。

### 票 06 修订（2026-10-26）

- **新增说法「老样子」**：占 5%；只有她和这位用户至少玩完过一次光顾才出，新手头 3 次也能出。上次光顾她点过的任一款都算对，没有「上得最好」这一档。不受票 04「第一单避开上次点过的」那条限制。备忘写「她要上次那款」。
- **直说饮品名**从 45% 改成 40%。
- **一次点两杯**仍然不收。同伴一起来这一版不做，两人怎么点单不用再看。
