# 01: 好感度放慢：往上的步子缩到十分之一，忍耐度和分数分开算

**What to build:** 天天来、每天那次抽奖都送同一位的人，信任到亲近约两周、到亲密约五周；只打字的人约一个月、两个月。她警告、挂断、结束对话的时机和现在完全一样，50 以下的恢复尺子不动，档位起点和正常值不动，已有用户的数值不迁移。只改好感度模块和它的文档，不碰日程。往上的步子一律缩到十分之一：回合按判断等级的步子从 (−5, −2, 0, +1, +2) 改成 (−1.5, −0.5, 0, +0.1, +0.2)，每天上限 6 → 0.6，不该说的话 −10 不动，「操纵不加分」不动；礼物普通 / 少见 / 稀有 3 / 5 / 7 → 0.3 / 0.5 / 0.7，喜欢的再 +3 → +0.3，不设每天上限；冷却中的礼物从「最多 +3」改成**一律 +3**（固定值，不再取 min），四件解除冷却的手感留着。**她的忍耐度和分数分开算**：警告、挂断、结束对话仍按最近几个回合「伤了多少」累加，但每个回合的「伤」不再等于它的减分，而是按等级查一张权重表：不舒服（等级 1）2、伤到她（等级 0）5、不该说的话 10；警告线 6、挂断线 12、回合数 8、每通不该说的话 2 都不动。这张权重表就是旧的减分数，所以库里已存回合的「伤」和新权重同一尺度，不用迁移。文档：好感度规格（`.scratch/affinity/spec.md`）的「数值」「推算」两段、礼物规格（`.scratch/gifts/spec.md`）礼物目录那条、「加分和概率放在好感度的数值模块里」那条、Further Notes「一次抽奖平均约 +4」那句改成新数；推算写：认真处的人每天约 +1.0，信任到亲近 15 天、到亲密 35 天；只打字 0.6 / 天，25 天、58 天；每天两次抽奖时 11 天、25 天；一次不舒服抵不到一天的好话，一次伤到她抵两三天，一次不该说的话抵十天多，信任到冷却仍是五次不该说的话。看板不加任何看升档快慢的数，不单独发公告。见规格「好感度放慢」一节和 Testing Decisions「好感度放慢」。
