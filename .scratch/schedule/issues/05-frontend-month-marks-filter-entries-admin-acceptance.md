# 05: 前端：月视图记号、筛选「日程」、只看她、入口、后台卡和看板，整块 Playwright 验收

**What to build:** 日程在日历的其他地方和入口都接上，后台能开关、看板看得到人数，然后把整块在本地构建版上走一遍。**月视图**加日程：格子里日程是 `--her-mark` 圆点（实心已保存、空心草稿），电脑上圆点后跟工作名、保存过的那一行铺 `--her-wall`（手机格子记号最多四个、电脑格子最多三行，照现在的 `CELL_MARKS` 和 `cellLines`）；点一天的清单里日程一行是她的头像、工作名、Meta 字号「下午 · 草稿 / 已保存」（`CalendarEvent` 加一类，图标、文字、键、行各补一个分支）。**筛选**加「日程」（`CalendarCheck`，`ScheduleIcon`），不按角色细分，和另外三类一排；老用户存的值里没有这一类，现在的存法会把它读成关着，所以改存法（改存「关掉的几类」，或读到旧值时补上新类），让老用户默认看到日程；日程关着时筛选没有这一项。**只看她**：`/play/calendar?who=<角色 id>` 时周视图和月视图只显示她的放置和她的待排（用票 04 的筛法），页顶一条同「礼物」子页预选的样子：她 24px 头像、「只看〇〇的日程」、右端 ✕（读屏「看全部」），点 ✕ 地址去掉 `who`；角色不存在时当作没有。**对话页更多菜单**：成就之后加「她的日程」（`CalendarIcon`），去 `/play/calendar?who=<她的 id>` 并把本机记住的视图切成周；日程关着时没有这一项；不放进好感度 Popover。**玩法页「日历」卡**：状态前面加「本周还有 n 项工作待排 · 」（n > 0 且本周已发布时），加在 `playCards` 里状态那一句前面；日程关着时只有「下一个」。**后台**：配置页「限额与玩法」标签加一张「日程」卡（只有开关，照「搭话」卡的样子、不「试」；`adminConfig` 多一项）；看板「好感度」标签加一格「本周排了日程的人数」（`lib/dashboard`），接口为 null 时不显示，好感度关着、日程开着时「好感度」标签也显示（`dashboardTabs` 的条件）。**关着时**的样子核对一遍：卡只有「下一个」、只有月视图没切换、筛选没「日程」、更多菜单没「她的日程」。**验收**（`docs/agents/local-acceptance.md`，本地构建版，Playwright，先起后端）：电脑先挑再放、亮格子、拿回草稿；手机点格子抽屉、「排到…」抽屉；保存条、确认框、保存后锁住；已开始的草稿退回；月 / 周切换记住；月视图的圆点和清单；筛选「日程」且老用户的旧值也看得到；「只看她」和更多菜单；玩法卡前缀；后台卡关掉后的样子；看板那一格。要造「已过 / 进行中 / 做完」的状态就改档案里的时区把「现在」挪到别的时间段，不用等；打几个回合看她说不说日程（对照票 03 实现说明里的句子）、搭话有没有带。能用接口造的自己造，只把要人看的留给用户（真机、打电话听）。见规格「界面」「后台和看板」「开关」和 Testing Decisions 前端部分。
