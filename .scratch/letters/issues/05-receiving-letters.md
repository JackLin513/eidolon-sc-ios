# 05: 收信：弹出、她的信、删除

**What to build:** 有没读过的信时，制作人打开网站（或从她的对话页切到别处）整屏弹出最早那封的信封；跳过的不再弹，换设备也一样。她的对话页页首能看到她写的所有信，对话列表上她那一行用小信封标出没读过的信。所有的信的列表里没读过的在最上面，其余按月分组。两个列表里都能删掉一封信。

见 spec「前端」「接口」，界面原型 `prototype/letters-ui` 的方案 C 加方案 A 的全局入口。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 接口：标弹过、删除（连语音一起删），别人的信 404；最新对话列表每一行多「有没有没读过的信」，现有 60 秒轮询顺带带回来。
- [ ] 弹出：有没读过也没弹过的信时弹最早一封；进入外壳时或从她的对话页切到别的页面时；在她的对话页上、通话中不弹；每次打开网站最多一封；信封出现时标弹过。选哪封、什么时候弹是纯函数，有单测。
- [ ] 她的对话页页首、电话键旁一个信封键（她有信时才出现），点开只列她的信、从新到旧（电脑对话框、手机底部抽屉）；从这里拆的信收起时飞回这个键。
- [ ] 对话列表上她那一行有没读过的信时，名字后面一枚小信封；读屏有一句说明。
- [ ] 全局列表改成：没读过的在最上面，其余按月分组、从新到旧（纯函数，有单测）。自动弹出的信收起时飞回页首信封键。
- [ ] 删除：两个列表里电脑右键、手机长按出「删除这封信」，确认框确认后删（照删历史对话的确认框）。
- [ ] 场合的叫法简短，不加说明小字。
- [ ] `DESIGN.md` 加一节「信」：信纸信封的固定浅色、她的颜色用在哪、信上的字号、拆开和收起的动效、列表行上的小信封、页首信封键的点；信纸信封的固定色进对比度测试。
- [ ] 本地构建版上用 Playwright 看弹出的时机（对话页上不弹、切走后弹、跳过后不再弹）、两个列表、删除，电脑和手机各截图。
